# 자격증 소개 | 빅데이터분석기사은(는) 어떤 자격증인가

## 한 줄로 설명하면

데이터 분석 분야의 **국가기술자격(기사)**이다. 분석 기획, 데이터 전처리, 통계·머신러닝 모델링, 결과 해석을 확인하고 실기에서는 **Python 또는 R 코드로 직접 분석**한다.

:::tip 이런 사람에게 맞다
- 데이터 분석가, 데이터 사이언티스트, AI 엔지니어 희망자
- ADsP·SQLD 다음 단계를 찾는 학생
- 공공기관 데이터 직무를 준비하는 학생
:::

## 시험 한눈에

| 항목 | 내용 |
|---|---|
| 시행 | 한국데이터산업진흥원 |
| 필기 | 객관식 80문항, 4과목 |

## 따면 어디에 쓰나

- 데이터 직무에서 **국가기술자격**으로 분석 역량 증명
- 공공기관·공기업 데이터 직무 가산점
- 실기 준비 과정 자체가 파이썬 데이터 분석 실습이 된다

## 난이도와 준비 기간

- 필기는 ADsP와 범위가 겹치지만 머신러닝·딥러닝 비중이 더 크다
- **실기는 코드 작성 시험**이라 pandas·scikit-learn을 손에 익혀야 한다
- ADsP 보유자 기준 필기 1개월, 실기 1~2개월

빅데이터분석기사는 과학기술정보통신부·통계청 소관, **한국데이터산업진흥원**이 시행하는 국가기술자격이다. 데이터 분석 기획부터 수집·전처리, 통계와 머신러닝 모델링, 결과 해석까지 확인한다.

## 공부 순서

필기는 ADsP와 범위가 많이 겹치지만 **딥러닝·최적화·시각화** 비중이 더 크다. 실기는 **코드를 외워서 손이 기억하게** 해야 한다.

1. **1~2주** — 2과목 탐색(통계 기초)과 4과목 결과 해석(평가 지표): 실기 3유형과 이어진다
2. **3주** — 3과목 모델링: 알고리즘별 원리와 장단점
3. **4주** — 1과목 기획: 용어 암기
4. **5주** — 필기 기출 반복
5. **6~9주** — 실기 장의 코드를 직접 치면서 1·2·3유형 반복

# 1과목 · 빅데이터 분석 기획 | 빅데이터의 이해

## 빅데이터의 특징

| 특징 | 의미 |
|---|---|
| Volume (규모) | 데이터 양 |
| Variety (다양성) | 정형·반정형·비정형 |
| Velocity (속도) | 생성·처리 속도 |
| **Veracity (정확성·신뢰성)** | 데이터 품질 (4V) |
| **Value (가치)** | 비즈니스 가치 창출 (5V) |
| Validity, Volatility | 타당성, 휘발성 (7V) |

| 데이터 유형 | 예 |
|---|---|
| 정형 | RDB 테이블, CSV, 스프레드시트 |
| 반정형 | XML, HTML, JSON, 로그, 센서 데이터 |
| 비정형 | 텍스트, 이미지, 음성, 동영상 |

**DIKW 피라미드**: Data(가공 전 사실) → Information(의미 있는 정보) → Knowledge(체계화한 지식) → Wisdom(새로운 상황에 적용하는 통찰).

**암묵지와 형식지 (SECI)**: 공통화(암묵→암묵) → 표출화(암묵→형식) → 연결화(형식→형식) → 내면화(형식→암묵).

## 빅데이터의 가치와 활용

- 본질적 변화: 사전 처리 → **사후 처리**, 표본 조사 → **전수 조사**, 질 → **양**, 인과관계 → **상관관계**
- 가치 산정이 어려운 이유: 데이터 활용 방식(재사용·재조합), 새로운 가치 창출, 분석 기술의 급속한 발전
- 위기 요인과 통제: 사생활 침해 → **책임제**(동의제에서), 책임 원칙 훼손 → **결과 기반 책임**, 데이터 오용 → **알고리즘 접근 허용**(알고리즈미스트)

## 빅데이터 조직과 인력

| 조직 구조 | 특징 |
|---|---|
| 집중형 | 전담 조직이 모든 분석 수행. 우선순위 조정 쉬움, 현업과 이원화 우려 |
| 기능형 | 각 부서가 직접 분석. 전사적 관점 부족 |
| 분산형 | 분석 인력을 현업에 배치. 신속한 적용, 역할 분담 중요 |

**데이터 사이언티스트 역량**: 하드 스킬(빅데이터 이론 지식, 분석 기술 숙련), 소프트 스킬(통찰력 있는 분석, 설득력 있는 전달, 다분야 협력).

## 빅데이터 플랫폼과 기술

| 계층 | 구성 |
|---|---|
| 소프트웨어 계층 | 데이터 처리·분석 애플리케이션 |
| 플랫폼 계층 | 작업 스케줄링, 데이터·자원 할당, 프로파일링 |
| 인프라 계층 | 자원 배치, 노드·저장장치·네트워크 관리 |

| 기술 | 설명 |
|---|---|
| **하둡 (Hadoop)** | 분산 저장 **HDFS** + 분산 처리 **MapReduce** + 자원 관리 **YARN** |
| HDFS | 네임노드(메타데이터) + 데이터노드(블록 저장). 블록 기본 3중 복제 |
| MapReduce | Map(분할·처리) → Shuffle → Reduce(집계) |
| **Spark** | 메모리 기반 분산 처리 (MapReduce보다 빠름). Spark SQL, MLlib, Streaming |
| Hive | 하둡 데이터를 SQL(HiveQL)로 질의 |
| Pig | 스크립트(Pig Latin)로 데이터 흐름 처리 |
| HBase | 하둡 기반 컬럼형 NoSQL |
| ZooKeeper | 분산 시스템 코디네이션 |
| Oozie | 워크플로 스케줄러 |
| Mahout | 하둡 기반 머신러닝 라이브러리 |

## 개인정보와 데이터 3법

| 개념 | 설명 |
|---|---|
| 개인정보 | 살아 있는 개인을 알아볼 수 있는 정보 |
| **가명정보** | 추가 정보 없이는 개인을 알아볼 수 없게 처리. **통계 작성, 과학적 연구, 공익적 기록 보존** 목적이면 동의 없이 처리 가능 |
| 익명정보 | 더 이상 개인을 알아볼 수 없는 정보. 법 적용 제외 |
| **데이터 3법** | 개인정보 보호법, 정보통신망법, 신용정보법 (2020 개정) |
| **마이데이터** | 정보주체가 자기 정보를 주도적으로 관리·전송 요구 |

| 비식별화 기법 | 예 |
|---|---|
| 가명처리 | 홍길동 → 임꺽정 / 휴리스틱 가명화, 암호화, 교환 방법 |
| 총계처리 | 개별 값 → 합계·평균 |
| 데이터 삭제 | 식별자·일부 값 삭제 |
| 데이터 범주화 | 35세 → 30대 / 랜덤 올림, 범위 방법 |
| 데이터 마스킹 | 홍길동 → 홍○○ / 임의 잡음 추가, 공백·대체 |

**프라이버시 보호 모델**: **k-익명성**(같은 준식별자 값을 가진 레코드 k개 이상) → 동질성 공격 취약 → **l-다양성**(민감 정보가 l개 이상 다양) → 쏠림·유사성 공격 취약 → **t-근접성**(민감 정보 분포가 전체와 t 이하 차이). **차분 프라이버시**: 결과에 잡음을 더해 개인 포함 여부를 알 수 없게.

# 1과목 · 빅데이터 분석 기획 | 분석 계획과 데이터 수집·저장

## 분석 과제 정의

| 분석 대상 \ 방법 | 방법을 앎 | 방법을 모름 |
|---|---|---|
| **대상을 앎** | 최적화 (Optimization) | 솔루션 (Solution) |
| **대상을 모름** | 통찰 (Insight) | 발견 (Discovery) |

| 접근 방식 | 설명 |
|---|---|
| 하향식 (Top-Down) | 문제가 주어지고 해법을 찾음: 문제 탐색 → 문제 정의 → 해결 방안 탐색 → 타당성 검토 |
| 상향식 (Bottom-Up) | 데이터를 먼저 보고 문제를 정의. **비지도 학습**, 디자인 사고(발산), 프로토타이핑 |

| 분석 기법 유형 | 질문 |
|---|---|
| 기술 분석 (Descriptive) | 무슨 일이 일어났는가 |
| 진단 분석 (Diagnostic) | 왜 일어났는가 |
| 예측 분석 (Predictive) | 무슨 일이 일어날 것인가 |
| 처방 분석 (Prescriptive) | 무엇을 해야 하는가 |

## 분석 방법론

:::fig crisp

| 방법론 | 단계 |
|---|---|
| **KDD** | 데이터셋 선택 → 전처리 → 변환 → 데이터 마이닝 → 해석·평가 |
| **CRISP-DM** | 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개 (4레벨: 단계, 일반화 태스크, 세분화 태스크, 프로세스 실행) |
| **SEMMA** | Sample(추출) → Explore(탐색) → Modify(수정) → Model(모델링) → Assess(평가). SAS사 |
| **빅데이터 분석 방법론** | 분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가 및 전개. 계층: 단계(Phase) → 태스크(Task) → 스텝(Step) |

분석 프로젝트 관리 영역: 범위, 시간, 원가, 품질, 통합, 조달, 자원, 리스크, 의사소통, 이해관계자. **WBS**(작업 분할 구조)로 작업을 계층적으로 나눈다.

# 2과목 · 빅데이터 탐색 | 데이터 전처리

## 데이터 정제

| 결측값 유형 | 설명 |
|---|---|
| **MCAR** (완전 무작위 결측) | 결측이 어떤 변수와도 무관 |
| **MAR** (무작위 결측) | 다른 관측 변수와 관련 있지만 그 변수 자체 값과는 무관 |
| **MNAR** (비무작위 결측) | 결측이 그 변수 값 자체와 관련 (고소득자의 소득 무응답) |

| 결측값 처리 | 설명 |
|---|---|
| 단순 삭제 | 목록 삭제(행 전체), 쌍별 삭제(분석에 쓰는 변수만) |
| 단순 대치 | 평균·중앙값·최빈값 대치, 회귀 대치, **핫덱**(비슷한 다른 레코드 값), 콜드덱(외부 자료) |
| 다중 대치 | **대치 → 분석 → 결합** 3단계. 여러 번 대치해 불확실성 반영 |
| 모델 기반 | KNN 대치, 보간법 |

| 이상값 탐지 | 기준 |
|---|---|
| **ESD** | 평균 ± 3 표준편차 밖 |
| **사분위수 (IQR)** | Q1 − 1.5 × IQR 미만, Q3 + 1.5 × IQR 초과 (상자 그림) |
| Z-점수 | \|Z\| > 3 |
| 마할라노비스 거리 | 다변량 이상치 |
| 군집·밀도 기반 | DBSCAN, LOF, Isolation Forest |

이상값 처리: 삭제, 대체(평균·중앙값), **변환**(로그), **극단값 조정**(Winsorizing — 상·하한값으로 바꿈), **절단**(Trimming).

## 변수 처리

| 기법 | 설명 |
|---|---|
| **필터 (Filter)** | 통계량(상관계수, 카이제곱, 분산, 정보 이득)으로 변수를 미리 걸러냄. 빠름 |
| **래퍼 (Wrapper)** | 모델 성능으로 변수 조합 평가. **전진 선택, 후진 제거, 단계적 선택**, RFE. 정확하지만 느림 |
| **임베디드 (Embedded)** | 모델 학습 과정에서 선택. **라쏘(L1), 릿지(L2), 엘라스틱넷**, 의사결정나무 중요도 |

**차원 축소**: **PCA**(주성분 분석 — 분산을 최대로 보존하는 직교 축), **LDA**(선형 판별 — 클래스 분리 최대화, 지도 학습), **요인 분석**(잠재 요인), **SVD**(특이값 분해), **t-SNE**(고차원 시각화), **MDS**(다차원 척도법).

| 변수 변환 | 설명 |
|---|---|
| **정규화 (Min-Max)** | (x − min) / (max − min) → 0~1 |
| **표준화 (Z-score)** | (x − 평균) / 표준편차 → 평균 0, 표준편차 1 |
| 로그·제곱근 변환 | 오른쪽 꼬리가 긴 분포를 정규분포에 가깝게 |
| **Box-Cox 변환** | 정규성 확보를 위한 거듭제곱 변환 (양수만) |
| 구간화 (Binning) | 연속형 → 범주형 |
| **원-핫 인코딩** | 범주형 → 0/1 더미 변수 |
| 레이블 인코딩 | 범주 → 정수 |

**파생 변수**: 기존 변수를 조합해 새 의미를 만든 변수 (BMI = 몸무게 / 키²). **요약 변수**: 종합한 변수 (월별 구매 금액).

## 탐색적 데이터 분석 (EDA)

투키(Tukey)의 EDA 4주제: **저항성**(이상치에 강한 통계량), **잔차 해석**, **자료 재표현**(변환), **현시성**(시각화).

| 기술 통계 | 내용 |
|---|---|
| 중심 경향 | 평균, 중앙값, 최빈값, 절사평균 |
| 산포 | 분산, 표준편차, 범위, IQR, **변동계수(CV) = 표준편차 / 평균** |
| 분포 모양 | **왜도**(> 0 오른쪽 꼬리, 평균 > 중앙값 > 최빈값), **첨도**(정규분포 3, 초과첨도 0) |

| 상관 분석 | 대상 |
|---|---|
| **피어슨** | 연속형, 선형 관계, 정규성 가정 |
| **스피어만** | 순위(서열), 비선형 단조 관계, 비모수 |
| 켄달 타우 | 순위 일치 |
| 카이제곱 검정·크래머 V | 범주형 간 연관성 |

## 표본 추출과 확률분포

| 표본 추출 | 설명 |
|---|---|
| 단순 무작위 | 같은 확률로 무작위 |
| 계통 | 일정 간격 |
| **층화** | 이질적 층으로 나눠 각 층에서 무작위 (층 내 동질, 층 간 이질) |
| **군집(집락)** | 군집을 뽑아 군집 전체 조사 (군집 내 이질, 군집 간 동질) |

| 분포 | 평균 / 분산 | 용도 |
|---|---|---|
| 베르누이 | p / p(1−p) | 성공·실패 1회 |
| 이항 B(n, p) | np / np(1−p) | n번 중 성공 횟수 |
| **포아송** | **λ / λ** | 단위 시간·공간의 발생 횟수 |
| 기하 | 1/p | 첫 성공까지 시행 수 |
| 정규 N(μ, σ²) | μ / σ² | ±1σ 68%, ±2σ 95%, ±3σ 99.7% |
| t 분포 | | 모분산 모를 때 평균 검정. 자유도 ↑ → 정규분포 |
| **카이제곱** | | 분산 검정, 적합도·독립성 검정 |
| **F 분포** | | 두 집단 분산 비, 분산분석 |
| 지수 | 1/λ | 사건 간 대기 시간 |

**중심극한정리**: 모집단 분포와 관계없이 표본 크기가 크면(n ≥ 30) 표본평균은 정규분포 N(μ, σ²/n)에 가까워진다.

## 추정과 가설 검정

- **점추정** 좋은 추정량: 불편성, 효율성, 일치성, 충분성
- **구간추정**: 95% 신뢰구간 = x̄ ± 1.96 × σ/√n. 표본이 클수록, 신뢰수준이 낮을수록 구간이 좁아진다
- **표준오차** = σ / √n

| | H₀ 참 | H₀ 거짓 |
|---|---|---|
| H₀ 기각 | **1종 오류 (α)** | 검정력 (1 − β) |
| H₀ 채택 | 옳음 | **2종 오류 (β)** |

**p-value < 유의수준 α → 귀무가설 기각**.

| 목적 | 모수 검정 | 비모수 검정 |
|---|---|---|
| 한 집단 평균 | 단일표본 t검정 | 부호 검정, 윌콕슨 부호순위 |
| 대응 두 집단 | 대응표본 t검정 | 윌콕슨 부호순위 |
| 독립 두 집단 | 독립표본 t검정 (등분산 검정 먼저) | **만-위트니 U** (윌콕슨 순위합) |
| 세 집단 이상 | **일원분산분석 (ANOVA, F)** | **크루스칼-왈리스** |
| 범주형 | 카이제곱 (적합도·독립성·동질성) | |
| 상관 | 피어슨 | 스피어만 |
| 정규성 | **샤피로-윌크**, 콜모고로프-스미르노프, Q-Q plot | |

분산분석 사후 검정: 투키(Tukey HSD), 셰페, 본페로니, 던칸.

# 3과목 · 빅데이터 모델링 | 분석 모형 설계와 기법

## 분석 모형의 분류

| 구분 | 설명 | 기법 |
|---|---|---|
| **지도 학습** | 정답(레이블)이 있는 데이터로 학습 | 회귀, 로지스틱 회귀, 의사결정나무, SVM, KNN, 나이브 베이즈, 랜덤 포레스트, 인공신경망 |
| **비지도 학습** | 정답 없이 패턴 발견 | 군집(K-means, 계층적, DBSCAN), 연관 규칙, PCA, 오토인코더 |
| 준지도 학습 | 일부만 레이블 | |
| **강화 학습** | 보상을 최대화하도록 행동 학습 (에이전트, 환경, 상태, 행동, 보상) | Q-러닝, 정책 경사 |

**데이터 분할**: 학습(Train) / 검증(Validation) / 테스트(Test) — 보통 6:2:2 또는 7:3.

| 검증 기법 | 설명 |
|---|---|
| 홀드아웃 | 한 번 나눔 |
| **K-폴드 교차 검증** | K개로 나눠 K번 학습·검증 후 평균 |
| LOOCV | 하나씩 빼고 검증 (K = n) |
| **부트스트랩** | 복원 추출. 한 번도 뽑히지 않을 확률 약 **36.8%** → OOB 검증 |
| 계층별 K-폴드 | 클래스 비율 유지 |

## 회귀 분석

- 선형 회귀 가정: **선형성, 독립성, 등분산성, 정규성** (+ 다중공선성 없음)
- **결정계수 R²** = SSR / SST (설명력). 수정된 R²는 변수 수를 보정
- **다중공선성**: 독립변수끼리 강한 상관 → **VIF > 10**이면 심각. 해결: 변수 제거, PCA, 릿지
- 변수 선택: 전진 선택, 후진 제거, 단계적 선택. 기준 **AIC, BIC**(작을수록 좋음)
- **규제 회귀**: 릿지(L2, 계수 축소), **라쏘(L1, 계수를 0으로 → 변수 선택)**, 엘라스틱넷(L1 + L2)
- 잔차 진단: Q-Q plot(정규성), 잔차 vs 적합값(등분산성), **더빈-왓슨**(독립성, 2에 가까우면 자기상관 없음)

**로지스틱 회귀**: 종속변수가 범주형. 시그모이드 함수로 확률 출력. **오즈 = p / (1 − p)**, 계수 β의 **exp(β) = 오즈비**(x가 1 증가할 때 오즈의 배수). 추정은 **최대우도법(MLE)**.

## 의사결정나무

| 알고리즘 | 분리 기준 | 특징 |
|---|---|---|
| **CART** | 분류: **지니 지수** / 회귀: 분산 감소 | 이진 분리 |
| **C4.5 / C5.0** | **엔트로피**(정보 이득 비율) | 다지 분리 |
| **CHAID** | **카이제곱 통계량** / 회귀: F 통계량 | 다지 분리, 가지치기 없음 |

- 지니 지수 = 1 − Σpᵢ², 엔트로피 = −Σpᵢ log₂ pᵢ (순수할수록 0)
- 과대적합 방지: **가지치기**(사전·사후), 최대 깊이, 최소 샘플 수
- 장점: 해석 쉬움, 전처리 부담 적음 / 단점: 과대적합, 불안정

| **트랜스포머** | 셀프 어텐션. BERT, GPT의 기반 |

## 군집 분석

| 기법 | 설명 |
|---|---|
| **K-means** | K개 중심 → 할당 → 중심 갱신 반복. K 사전 결정, 이상치 민감. K 선택: **엘보우**, **실루엣 계수**(−1~1, 1에 가까울수록 좋음) |
| K-medoids | 실제 데이터(메도이드)를 중심으로. 이상치에 강함 |
| 계층적 군집 | 덴드로그램. 연결법: 단일(최단), 완전(최장), 평균, 중심, **와드**(군집 내 분산 증가 최소) |
| **DBSCAN** | 밀도 기반(eps, minPts). 임의 모양, 노이즈 처리, K 불필요 |
| 혼합 분포 군집 | **EM 알고리즘**(E: 소속 확률 계산, M: 모수 추정) |
| **SOM** | 자기조직화지도. 경쟁 학습, 고차원 → 2차원 |

거리: 유클리드, 맨해튼, 민코프스키, 체비셰프, **마할라노비스**(공분산 고려), 코사인 유사도, 자카드(범주형).

## 연관 분석

| 지표 | 공식 |
|---|---|
| 지지도 | P(A∩B) |
| 신뢰도 | P(B\|A) = P(A∩B) / P(A) |
| **향상도** | P(B\|A) / P(B). **1 = 독립, > 1 양의 상관(보완재), < 1 음의 상관(대체재)** |

알고리즘: **Apriori**(빈발 항목 집합, 최소 지지도), **FP-Growth**(FP-Tree, 빠름). 시간 순서를 고려하면 **순차 패턴 분석**.

## 자주 나오는 처리 패턴

```python
# 1) 정렬 후 상위 N개
top10 = df.sort_values("qsec", ascending=False).head(10)

# 2) 결측치
df["age"].isnull().sum()

cond = df[(df["cyl"] == 4) & (df["hp"] >= 100)]
print(len(cond))

# 4) 그룹별 집계
g = df.groupby("gear")["mpg"].mean()
print(g.idxmax(), round(g.max(), 2))

# 5) 이상치 (IQR)
q1, q3 = df["mpg"].quantile([0.25, 0.75])
iqr = q3 - q1
out = df[(df["mpg"] < q1 - 1.5 * iqr) | (df["mpg"] > q3 + 1.5 * iqr)]

# 6) 스케일링
from sklearn.preprocessing import MinMaxScaler, StandardScaler
df["qsec_mm"] = MinMaxScaler().fit_transform(df[["qsec"]])
df["qsec_z"] = (df["qsec"] - df["qsec"].mean()) / df["qsec"].std()

df["date"] = pd.to_datetime(df["date"])
df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["dow"] = df["date"].dt.dayofweek          # 월=0 … 일=6

# 8) 문자열
df["name"].str.contains("kim").sum()
df["code"].str[:2]                            # 앞 2글자

# 9) 순위, 누적, 이동평균
df["rank"] = df["score"].rank(method="min", ascending=False)

# 10) 빈도, 비율
df["city"].value_counts()

# 11) 결과는 정수로 요구하면 int(), 반올림이면 round()
print(int(result))

```

- 표준편차: pandas `std()`는 **표본 표준편차(ddof=1)**, numpy `np.std()`는 **모표준편차(ddof=0)**가 기본값이다
- `fillna` 결과를 다시 대입하지 않으면 원본이 바뀌지 않는다
- 조건 필터링에서 `and`, `or`가 아니라 `&`, `|`를 쓰고 각 조건을 괄호로 감싼다
- "소수점 넷째 자리에서 반올림"은 `round(x, 3)`
:::

# 실기 · 빅데이터 분석 실무 | 작업형 2유형 — 모델 구축

## 표준 흐름

배점이 가장 큰 유형이다. **분류**(예: 고객 이탈 여부, 성별)와 **회귀**(예: 가격, 매출) 중 하나가 나오며, 테스트 데이터의 예측 결과를 지정한 형식의 CSV로 저장한다. 평가 지표(ROC-AUC, F1, RMSE 등)로 채점한다.

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score, f1_score

train = pd.read_csv("data/customer_train.csv")
test = pd.read_csv("data/customer_test.csv")

# 1. 타깃 분리, ID 제외
y = train.pop("target")
test_id = test["ID"]
train = train.drop(columns=["ID"])
test = test.drop(columns=["ID"])

# 2. 결측치 처리 (수치형은 중앙값, 범주형은 최빈값)
num_cols = train.select_dtypes(exclude="object").columns
cat_cols = train.select_dtypes(include="object").columns
for c in num_cols:
    med = train[c].median()
    train[c] = train[c].fillna(med); test[c] = test[c].fillna(med)
for c in cat_cols:
    train[c] = train[c].fillna("missing"); test[c] = test[c].fillna("missing")

# 3. 범주형 인코딩 — train과 test를 함께 원-핫 인코딩해 열을 맞춤
all_df = pd.concat([train, test])
all_df = pd.get_dummies(all_df, columns=list(cat_cols))
train = all_df.iloc[:len(train)]
test = all_df.iloc[len(train):]

# 4. 검증용 분할
X_tr, X_val, y_tr, y_val = train_test_split(train, y, test_size=0.2, random_state=42, stratify=y)

# 5. 학습·평가
model = RandomForestClassifier(n_estimators=300, max_depth=8, random_state=42)
model.fit(X_tr, y_tr)
proba = model.predict_proba(X_val)[:, 1]
print("ROC-AUC:", roc_auc_score(y_val, proba))
print("F1:", f1_score(y_val, model.predict(X_val)))

# 6. 전체 데이터로 다시 학습 후 예측
model.fit(train, y)
pred = model.predict_proba(test)[:, 1]

# 7. 제출 형식에 맞춰 저장 (문제에 적힌 열 이름·파일명 그대로)
pd.DataFrame({"ID": test_id, "pred": pred}).to_csv("result.csv", index=False)
print(pd.read_csv("result.csv").head())     # 저장 확인
```

회귀 문제는 `RandomForestRegressor`와 RMSE로 바꾸면 된다.

```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error, r2_score
model = RandomForestRegressor(n_estimators=300, random_state=42)
model.fit(X_tr, y_tr)
pred = model.predict(X_val)
print("RMSE:", mean_squared_error(y_val, pred) ** 0.5, "R2:", r2_score(y_val, pred))
```

:::exam 2유형 채점 포인트
- **제출 형식**(열 이름, 행 수, index=False)을 틀리면 점수가 크게 깎인다
- 분류에서 확률을 요구하는지(`predict_proba`), 클래스를 요구하는지(`predict`) 문제를 다시 읽는다
- test 데이터에 train과 **같은 전처리**를 해야 한다 (scaler는 train으로 fit, test는 transform만)
- 랜덤 포레스트만으로도 합격 점수가 나오는 경우가 많다. 시간이 남으면 XGBoost·LightGBM 비교
:::

# 실기 · 빅데이터 분석 실무 | 작업형 3유형 — 통계 검정

## 검정별 코드

```python
from scipy import stats

# 1) 단일표본 t검정: 평균이 기준값과 같은가
t, p = stats.ttest_1samp(df["weight"], 100)

# 2) 독립표본 t검정: 두 집단 평균 비교 (등분산 가정 여부)
print(stats.levene(a, b))                       # 등분산 검정
t, p = stats.ttest_ind(a, b, equal_var=True)

# 3) 대응표본 t검정: 전후 비교
t, p = stats.ttest_rel(before, after)

# 4) 정규성
print(stats.shapiro(df["x"]))

# 5) 일원분산분석
f, p = stats.f_oneway(g1, g2, g3)

# 6) 카이제곱 독립성 검정
table = pd.crosstab(df["sex"], df["survived"])
chi2, p, dof, expected = stats.chi2_contingency(table)

# 7) 카이제곱 적합도 검정
chi2, p = stats.chisquare(f_obs=[50, 30, 20], f_exp=[40, 40, 20])

# 8) 비모수
stats.wilcoxon(before, after)       # 대응
stats.mannwhitneyu(a, b)            # 독립 두 집단
stats.kruskal(g1, g2, g3)           # 세 집단 이상

# 9) 상관
stats.pearsonr(df["x"], df["y"]); stats.spearmanr(df["x"], df["y"])
```

### 회귀·로지스틱 회귀 결과 해석 (statsmodels)

```python
import statsmodels.formula.api as smf
import numpy as np

ols = smf.ols("price ~ area + rooms + C(region)", data=df).fit()
print(ols.summary())            # 계수, p-value, R², AIC
print(ols.params["area"], ols.pvalues["area"], ols.rsquared)

print(logit.params)

```
