# 자격증 소개 | 정보처리산업기사은(는) 어떤 자격증인가

## 한 줄로 설명하면

정보처리기사의 한 단계 아래 **국가기술자격**이다. 범위는 기사와 많이 겹치지만 과목 수가 적고 난도가 조금 낮다. 응시 자격 문턱이 낮아 대학 재학생·전문대생이 먼저 따는 경우가 많다.

:::tip 이런 사람에게 맞다
- 전문대 졸업(예정)자, 4년제 2학년 이상 재학생
- 정보처리기사 응시 자격이 아직 안 되는 학생
- 공공기관·공기업 가산점을 빨리 확보하고 싶은 학생
:::

## 시험 한눈에

| 항목 | 내용 |
|---|---|
| 시행 | 한국산업인력공단 (Q-Net) |
| 필기 | 객관식 3과목 |
| 실기 | 필답형 (코드 해석, SQL, 용어) |
| 응시 자격 | 2년제 졸업(예정), 4년제 2학년 이상 수료, 기능사 + 실무 1년 등 |
| 시행 횟수 | 연 3회 |

## 따면 어디에 쓰나

- 공기업·공공기관 전산직 가산점 (기관마다 기사와 점수 차이)
- 개발 직군 서류의 기초 역량 증명
- 이후 **실무 경력 1년**을 쌓으면 정보처리기사 응시 자격이 생긴다

## 난이도와 준비 기간

- 기사보다 범위가 좁아 준비 부담이 적다
- 그래도 **실기 코드 해석**은 기사와 같은 방식이라 언어 기초가 필요하다
- 비전공자 기준 필기 1개월, 실기 2개월 정도

## 함께 보면 좋은 자격증 · 추천 순서

- 다음 단계 → **정보처리기사**
- 함께 → **SQLD**(DB), **리눅스마스터 2급**(서버)
- 응시 자격이 전혀 없으면 → **프로그래밍기능사**

:::exam 준비할 때 알아 둘 것
- 지금 응시할 수 있는 IT 국가자격 중 공신력이 높은 자격이다
- 기사와 공부 내용이 거의 같아 나중에 정보처리기사로 올라가기 쉽다
- 실기 대비는 C·Java·Python 기초 문법 공부와 함께 하면 효율적이다
:::

## 더 자세한 정보는 여기서 확인

- **Q-Net** (q-net.or.kr): 시험 일정, 원서 접수, 응시자격 자가진단, 출제기준(과목별 세부 항목), 합격자 발표
- **각 기관 채용공고 / 잡알리오** (job.alio.go.kr): 공공기관별 자격증 가산점·우대 여부

시험 일정·응시료·출제 기준은 해마다 바뀔 수 있다. **응시 전에 위 공식 사이트에서 최신 공고를 꼭 확인**하자.

## 자주 묻는 질문

- **Q. 산업기사 따고 기사도 따야 하나요?** 목표가 공기업이면 기사까지 권장한다.

# 시작하기 | 시험 구성과 공부 순서

## 정보처리산업기사는 어떤 시험인가

정보처리산업기사는 한국산업인력공단이 시행하는 국가기술자격이다. 정보시스템 기반 기술(운영체제·네트워크·설계·테스트), 프로그래밍 언어, 데이터베이스를 활용해 소프트웨어를 구현하는 능력을 확인한다. 전문대 졸업(예정)자 등 기사보다 응시 자격 문턱이 낮다.

| 항목 | 내용 |
|---|---|
| 시행 | 한국산업인력공단 (큐넷 q-net.or.kr) |
| 필기 과목 | 1과목 정보시스템 기반 기술 · 2과목 프로그래밍 언어 활용 · 3과목 데이터베이스 활용 |
| 필기 방식 | 객관식 4지 택일, CBT. 과목당 20문항 (총 60문항) |
| 필기 합격 | 과목당 40점 이상, 전 과목 평균 60점 이상 |
| 실기 | 정보처리 실무, **필답형**. 100점 만점 60점 이상 |
| 응시 자격 | 2년제 전문대 졸업(예정)자, 관련 실무 경력 1년 이상, 기능사 + 실무 1년 등 (큐넷 자가진단) |
| 필기 면제 | 필기 합격 후 2년간 |

:::warn 접수 전에 꼭 다시 확인할 것
2026년 11월 기준으로 정리했다. 시험 시간, 응시료, 일정은 큐넷 공고를 확인하자.
:::

## 실기 준비 방법

실기는 필답형으로 직접 답을 쓴다. 정보처리기사 실기와 유형이 비슷하며 **코드 실행 결과, SQL, 용어 쓰기, 계산**이 중심이다.

:::exam 감점 피하는 법
- 코드 출력은 공백·줄바꿈까지 그대로
- 용어는 정확한 철자. 약어를 묻는지 풀네임을 묻는지 확인
- SQL은 키워드 철자, 따옴표, 세미콜론까지
:::

Q. 다음 C 코드의 출력 결과는?

```c
#include <stdio.h>
int main(void) {
    int i, s = 0;
    for (i = 1; i <= 10; i++) {
        if (i % 3 == 0) s += i;
    }
    printf("%d", s);
    return 0;
}
```
1) 18
2) 15
3) 30
4) 12
> 정답 1 | 3 + 6 + 9 = 18.

Q. 다음 Python 코드의 출력 결과는?

```python
s = "information"
print(s[2:6], s.count("i"), s.upper()[-3:])
```
1) form 2 ION
2) for 2 ion
3) form 1 ION
4) orma 2 ION
> 정답 1 | s[2:6] = 'form', 'i'는 2개, 대문자 뒤 3글자 'ION'.

Q. 다음 Java 코드의 출력 결과는?

```java
public class Main {
    public static void main(String[] args) {

        int sum = 0;
        for (int x : a) {
            if (x == 6) continue;
            sum += x;
        }
        System.out.println(sum);
    }
}
```
1) 20
2) 14
3) 12
4) 8
> 정답 2 | 6을 건너뛰고 2 + 4 + 8 = 14.
