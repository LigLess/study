# 자격증 소개 | 정보처리기사은(는) 어떤 자격증인가

## 한 줄로 설명하면

IT 개발 직군에서 가장 많이 요구하는 **국가기술자격**이다. 소프트웨어 설계·개발, 데이터베이스, 프로그래밍 언어, 정보보안 기초를 두루 확인한다. 공기업·공공기관 전산직 채용에서 가산점이나 지원 자격으로 자주 쓰인다.

:::tip 이런 사람에게 맞다
- 개발자(백엔드·프론트엔드·앱)로 취업하려는 4년제 졸업(예정)자
- 공기업·공무원 전산직을 준비하는 학생
- 비전공자인데 IT 기초를 체계적으로 한 번 훑고 싶은 사람
:::

## 시험 한눈에

| 항목 | 내용 |
|---|---|
| 시행 | 한국산업인력공단 (Q-Net) |
| 필기 | 객관식, 과목당 40점 이상 · 평균 60점 이상 |
| 실기 | 필답형 (C·Java·Python 코드 해석, SQL, 용어 서술), 60점 이상 |
| 응시 자격 | 4년제 졸업(예정), 동일 분야 산업기사 + 실무 1년 등 |
| 시행 횟수 | 연 3회 |

## 따면 어디에 쓰나

- **개발 직군 신입 채용**: 서류에서 기본 역량 증명
- **공기업·공공기관 전산직**: 가산점, 지원 자격
- **군 전산 특기**, 일부 대기업 사내 우대
- 정보보안기사·빅데이터분석기사 등 다른 기사 공부의 기초가 된다

## 난이도와 준비 기간

- 필기는 범위가 넓지만 기출 반복으로 대부분 합격한다
- **실기(코드 해석)가 진짜 관문**이다. 비전공자는 C·Java·Python 기초 문법이 없으면 실기에서 막힌다
- 비전공자 기준 필기 1~2개월, 실기 2~3개월

## 함께 보면 좋은 자격증 · 추천 순서

- 응시 자격이 안 되면 → **정보처리산업기사**(2년제·대학 재학) 또는 **프로그래밍기능사**부터
- 데이터 쪽 → **SQLD**, **ADsP**
- 보안 쪽 → **리눅스마스터 2급** → **정보보안기사**

:::exam 준비할 때 알아 둘 것
- 이 교본은 시험 범위를 정리한 자료다. 실기는 직접 코드를 짜고 결과를 손으로 따라가 보는 연습을 해야 합격할 수 있다
- 실기 코드 문제에서 포기하는 경우가 많다. C·Java·Python 기초 문법을 먼저 익혀 두면 실기가 훨씬 쉬워진다
- 자격증만으로 취업하지는 않는다. **포트폴리오(프로젝트)**와 함께 준비해야 서류에서 의미가 커진다
:::

## 더 자세한 정보는 여기서 확인

- **Q-Net** (q-net.or.kr): 시험 일정, 원서 접수, 응시자격 자가진단, 출제기준(과목별 세부 항목), 합격자 발표
- **각 기관 채용공고 / 잡알리오** (job.alio.go.kr): 공공기관별 자격증 가산점·우대 여부

시험 일정·응시료·출제 기준은 해마다 바뀔 수 있다. **응시 전에 위 공식 사이트에서 최신 공고를 꼭 확인**하자.

## 자주 묻는 질문

- **Q. 비전공자도 딸 수 있나요?** 응시 자격만 되면 가능하다. 필기는 암기, 실기는 코딩 기초가 필요하다.
- **Q. 이것만 있으면 취업되나요?** 기본 증명이다. 개발 직군은 프로젝트 경험을 더 본다.
- **Q. 필기 붙고 실기 떨어지면?** 필기 합격일부터 2년간 필기가 면제된다.

## 정보처리기사는 어떤 시험인가

정보처리기사는 한국산업인력공단이 시행하는 국가기술자격이다. 소프트웨어를 설계·구현·테스트하고 배포하는 개발 직무 능력을 확인한다. 개발자 취업, 공기업 전산직 가점, 기술 자격 수당 등에 널리 쓰인다.

### 2027년 출제기준 변경 (2027.1.1 ~ 2029.12.31)

| 구분 | 2026년까지 | 2027년부터 |
|---|---|---|
| 필기 과목 | 소프트웨어 설계, 소프트웨어 개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축관리 (5과목) | **소프트웨어 개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축관리 (4과목)** |
| 필기 문항·시간 | 100문항 / 2시간 30분 | **80문항 / 2시간** (과목당 20문항) |
| 실기 | 정보처리 실무, 필답형 2시간 30분 | 변경 없음 |

- 기존 **소프트웨어 설계**와 **소프트웨어 개발**, 방법론 활용이 새 **소프트웨어 개발** 과목으로 합쳐졌다.
- 빠진 항목: 요구사항 확인의 '현행 시스템 분석', 소프트웨어 개발의 '데이터 입출력 구현'. **자료구조**는 프로그래밍 언어 활용(기본 문법 활용)으로 옮겨졌다.
- 이 교본은 2027년 기준으로 묶었고, 2026년 기준 범위도 빠짐없이 들어 있다.

## 공부 순서

필기는 기출 반복으로 합격하는 사람이 많지만, **실기 합격률은 회차에 따라 10~20%대**로 낮다. 실기의 절반 가까이가 **코드 실행 결과 쓰기**와 **SQL**이라서, 필기 공부 때부터 코드를 직접 따라가는 연습을 해야 한다.

1. **1~2주** — 3과목(프로그래밍 언어 활용): C·Java·Python 코드를 변수표로 따라가는 연습. 실기까지 이어진다
2. **3주** — 2과목(데이터베이스 구축): SQL은 직접 써 본다
3. **4주** — 1과목(소프트웨어 개발): 표 위주로 암기
4. **5주** — 4과목(정보시스템 구축관리): 용어 암기, 직전에 한 번 더
5. **6주** — 기출문제 5회 이상. 이후 실기 장으로 넘어간다

## 실기 시험의 모양

실기는 **필답형**으로, 문제를 읽고 답을 직접 쓴다. 보통 20문항 안팎이며 문항당 배점이 크다(부분 점수가 거의 없다). 출제 범위는 필기와 같은 NCS 직무 범위 전체다.

| 유형 | 비중 (최근 경향) | 대비 |
|---|---|---|
| 코드 실행 결과 | 가장 많음. C, Java, Python 각 2~4문항 | 변수표, 포인터, 상속, 재귀, 배열 |
| SQL | 2~3문항 | 결과 행 수·값 계산, 빈칸 채우기, 직접 작성 |
| 용어 쓰기 | 다수 | 설명을 읽고 용어(영문 약어 포함) 쓰기 |
| 보기에서 고르기 | 일부 | 디자인 패턴, 테스트 기법, 결합도·응집도, 공격 기법 |
| 계산 | 일부 | 서브넷, 페이지 교체, 순환 복잡도, 스케줄링 |

:::exam 감점 피하는 법
- 답을 **정확한 철자**로. 영문 약어와 한글을 함께 묻는 문제는 둘 다 쓴다
- 코드 출력은 **공백·줄바꿈까지** 그대로. `printf("%d ", i)`면 숫자 뒤에 공백이 있다
- "모두 고르시오"는 하나라도 틀리면 0점
- SQL은 **세미콜론, 따옴표, 키워드 철자**까지 정확히
:::

## 코드 문제 연습

:::quiz
Q. 다음 C 코드의 출력 결과는?

```c
#include <stdio.h>
int main(void) {
    int a[5] = {5, 3, 8, 1, 9};
    int i, j, t;
    for (i = 0; i < 4; i++)
        for (j = 0; j < 4 - i; j++)
            if (a[j] > a[j + 1]) { t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
    for (i = 0; i < 5; i++) printf("%d", a[i]);
    return 0;
}
```
1) 13589
2) 98531
3) 53819
4) 15389
> 정답 1 | 버블 정렬 오름차순. 출력 형식에 공백이 없으므로 13589.

Q. 다음 Java 코드의 출력 결과는?

```java
class A {
    int f(int x) { return x * 2; }
    int g(int x) { return f(x) + 1; }
}
class B extends A {
    int f(int x) { return x * 3; }
}
public class Main {
    public static void main(String[] args) {
        A obj = new B();
        System.out.println(obj.g(4));
    }
}
```
1) 9
2) 13
3) 8
4) 12
> 정답 2 | g는 A의 것이지만 그 안의 f(x)는 실제 객체 B의 f가 호출된다. 4 × 3 + 1 = 13.

Q. 다음 Python 코드의 출력 결과는?

```python
def f(lst, n):
    if n == 0:
        return lst
    lst.append(n)
    return f(lst, n - 1)

r = f([], 3)
print(r, len(r))
```
1) [1, 2, 3] 3
2) [3, 2, 1] 3
3) [3, 2, 1, 0] 4
4) [] 0
> 정답 2 | 3, 2, 1 순서로 추가되고 n = 0에서 반환.

Q. 다음 C 코드의 출력 결과는?

```c
#include <stdio.h>
int main(void) {
    char s[] = "ABCDE";
    char *p = s + 4;
    while (p >= s) {
        printf("%c", *p);
        p -= 2;
    }
    return 0;
}
```
1) ECA
2) EDCBA
3) ACE
4) EC
> 정답 1 | p가 E, C, A를 차례로 가리킨다.

Q. 다음 Java 코드의 출력 결과는?

```java
public class Main {
    static int cnt = 0;
    static void run(int n) {
        cnt++;
        if (n <= 1) return;
        run(n / 2);
        run(n / 2);
    }
    public static void main(String[] args) {
        run(4);
        System.out.println(cnt);
    }
}
```
1) 3
2) 5
3) 7
4) 4
> 정답 3 | run(4) → run(2) 두 번 → 각각 run(1) 두 번. 1 + 2 + 4 = 7번 호출.

Q. 다음 Python 코드의 출력 결과는?

```python
a = {1: 'a', 2: 'b'}
b = {v: k for k, v in a.items()}
s = 0
for k in b:
    s += b[k]
print(s, list(b.keys()))
```
1) 3 ['a', 'b']
2) 3 [1, 2]
3) 'ab' [1, 2]
4) 오류
> 정답 1 | 키와 값을 뒤집으면 {'a': 1, 'b': 2}. 값의 합 3.

## 과목 섞어 풀기

:::quiz
Q. 애자일 방법론 XP의 핵심 가치가 아닌 것은?
1) 의사소통
2) 단순성
3) 문서화
4) 용기
> 정답 3 | 의사소통, 단순성, 용기, 존중, 피드백. (개발 방법론)

Q. 모듈 간 전역 변수를 공유하는 결합도는?
1) 자료 결합도
2) 제어 결합도
3) 공통 결합도
4) 내용 결합도
> 정답 3 | (설계)

Q. 상향식 통합 테스트에서 사용하는 것은?
1) 스텁
2) 드라이버
3) 오라클
4) 하네스만
> 정답 2 | (테스트)

Q. 키의 성질 중 유일성은 만족하지만 최소성은 만족하지 않을 수 있는 키는?
1) 후보키
2) 기본키
3) 슈퍼키
4) 외래키
> 정답 3 | (데이터베이스 이론)

Q. 트랜잭션 ACID 중 병행 제어와 가장 관련 깊은 특성은?
1) 원자성
2) 일관성
3) 격리성
4) 영속성
> 정답 3 | (트랜잭션)

Q. SQL에서 뷰에 대한 설명으로 틀린 것은?
1) 가상 테이블이다
2) ALTER 문으로 정의를 변경할 수 있다
3) 논리적 독립성을 제공한다
4) 뷰 위에 다른 뷰를 정의할 수 있다
> 정답 2 | 뷰는 ALTER로 바꿀 수 없다. (SQL)

Q. C 언어에서 `int a = 10; a += a++ ;`처럼 같은 변수를 한 식에서 여러 번 변경하는 코드를 피해야 하는 이유는?
1) 컴파일 오류가 나기 때문
2) 결과가 컴파일러마다 달라질 수 있기 때문
3) 실행 속도가 느려지기 때문
4) 메모리를 많이 쓰기 때문
> 정답 2 | 표준에서 정의되지 않은 동작이다. 시험에서는 왼쪽부터 순서대로 계산한다고 보면 된다. (C)

Q. Python에서 `print(list(range(10, 0, -3)))`의 결과는?
1) [10, 7, 4, 1]
2) [10, 7, 4]
3) [9, 6, 3]
4) [10, 6, 3, 0]
> 정답 1 | (Python)

Q. 스택에 A, B, C를 차례로 넣고 하나를 꺼낸 뒤 D를 넣고 두 개를 꺼내면, 꺼낸 순서는?
1) C D B
2) A B D
3) C B D
4) D C B
> 정답 1 | Push A, B, C → Pop C → Push D → Pop D, Pop B. (자료구조)

Q. 교착상태 해결 방법 중 은행원 알고리즘이 속하는 것은?
1) 예방
2) 회피
3) 발견
4) 회복
> 정답 2 | (운영체제)

Q. TCP/IP에서 오류 메시지를 전달하고 ping 명령에 사용되는 프로토콜은?
1) ARP
2) ICMP
3) IGMP
4) UDP
> 정답 2 | (네트워크)

Q. 다음 중 비대칭키 암호 알고리즘은?
1) DES
2) AES
3) ECC
4) SEED
> 정답 3 | (보안)

Q. 버퍼 오버플로 공격 대응 기법이 아닌 것은?
1) 스택 가드
2) ASLR
3) 스택 실드
4) 솔트
> 정답 4 | 솔트는 비밀번호 해시 보안 기법이다. (보안)

Q. 데이터를 발생지 가까운 곳에서 처리해 지연을 줄이는 컴퓨팅은?
1) 클라우드 컴퓨팅
2) 엣지 컴퓨팅
3) 그리드 컴퓨팅
4) 서버리스
> 정답 2 | (신기술)

Q. RAID 레벨 중 미러링 방식은?
1) RAID 0
2) RAID 1
3) RAID 5
4) RAID 6
> 정답 2 | (신기술·하드웨어)
:::

:::tip 시험 직전 체크리스트
- 결합도 "자스제외공내", 응집도 "기순교절시논우"
- 디자인 패턴 생성 5 / 구조 7 / 행위 11, UML 다이어그램 구조·행위 구분
- 테스트: 스텁(하향식)·드라이버(상향식), 블랙박스·화이트박스 기법, 커버리지, V 모델
- 정규화 "도부이결다조", 키(유일성·최소성), 무결성, 관계 대수 기호
- SQL: GROUP BY–HAVING, 조인, DDL/DML/DCL, 트리거·프로시저
- C 포인터, Java 오버라이딩·업캐스팅, Python 슬라이싱·컬렉션
- 스케줄링 HRN 공식, 페이지 교체, 교착상태 4조건
- OSI 7계층, TCP/UDP, 서브넷 계산
- 공격 기법(스머프·랜드·티어드롭), 암호 알고리즘 분류, 접근통제 모델
:::
