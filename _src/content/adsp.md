# 자격증 소개 | ADsP (데이터분석 준전문가)은(는) 어떤 자격증인가

## 한 줄로 설명하면

한국데이터산업진흥원이 시행하는 **국가공인 민간자격**이다. 데이터의 이해, 분석 기획, R 기반 통계·데이터 마이닝을 객관식으로 확인한다. 데이터 분야 입문 자격으로 가장 많이 딴다.

:::tip 이런 사람에게 맞다
- 데이터 분석가, 데이터 기반 마케터·기획자를 꿈꾸는 학생
- 문과·비전공자로 데이터 분야에 관심이 생긴 학생
- 빅데이터분석기사 전에 기초를 다지려는 학생
:::

## 시험 한눈에

| 항목 | 내용 |
|---|---|
| 시행 | 한국데이터산업진흥원 (dataq.or.kr) |
| 방식 | 객관식, 3과목 |
| 합격 | 총점 60점 이상, 과목별 40% 이상 |
| 응시 자격 | 없음 |
| 유효 기간 | 없음 (평생) |

## 따면 어디에 쓰나

- 데이터 분석·마케팅·기획 직무 서류에서 데이터 이해도 증명
- 공공기관 데이터 직무 우대
- **빅데이터분석기사** 필기와 범위가 많이 겹친다

## 난이도와 준비 기간

- 실기가 없어 데이터 자격 중 진입 장벽이 가장 낮다
- 3과목(통계·R 분석)이 가장 어렵다
- 비전공자 기준 3~6주

## 함께 보면 좋은 자격증 · 추천 순서

- 함께 → **SQLD** (데이터 직무의 기본 세트)
- 다음 → **빅데이터분석기사**, **AICE**
- 실무 도구 → 파이썬 데이터 분석

:::exam 준비할 때 알아 둘 것
- ADsP는 '데이터를 안다'는 증명이고, 실제 분석 실력은 **파이썬·SQL 실습**으로 보여 줘야 한다
- SQLD와 함께 따면 데이터 직무 서류가 탄탄해진다
- 3과목(통계·분석)에서 막히는 경우가 많다. 공식을 외우기보다 개념의 의미를 이해하는 데 시간을 쓰자
:::

## 더 자세한 정보는 여기서 확인

- **데이터자격검정** (dataq.or.kr): 시험 일정, 접수, 응시료, 과목별 출제 범위, 합격 기준, 자격 확인, 유효기간
- **각 기관 채용공고 / 잡알리오** (job.alio.go.kr): 공공기관별 자격증 가산점·우대 여부

시험 일정·응시료·출제 기준은 해마다 바뀔 수 있다. **응시 전에 위 공식 사이트에서 최신 공고를 꼭 확인**하자.

## 자주 묻는 질문

- **Q. 수학 못해도 되나요?** 기초 통계 개념 수준이다. 공식 암기보다 의미를 이해하면 된다.
- **Q. 따면 바로 분석가 되나요?** 입문 증명이다. 분석 프로젝트 경험이 함께 있어야 한다.

# 시작하기 | 시험 구성과 공부 순서

## ADsP는 어떤 시험인가

ADsP(Advanced Data Analytics Semi-Professional, 데이터분석 준전문가)는 한국데이터산업진흥원이 주관하는 국가공인 민간자격이다. 데이터를 이해하고, 분석 프로젝트를 기획하고, 통계와 데이터마이닝으로 분석하는 기본 역량을 확인한다. 응시 자격 제한이 없고, 한 번 따면 갱신 없이 계속 유효하다.

| 항목 | 내용 |
|---|---|
| 주관 | 한국데이터산업진흥원 (데이터자격검정 dataq.or.kr) |
| 시험 방식 | 필기(PBT) 객관식 4지선다 50문항, 실기 없음 |
| 시험 시간 | 90분 |
| 과목 | 1과목 데이터 이해 · 2과목 데이터 분석 기획 · 3과목 데이터 분석 |
| 문항 배분 | 10문항 · 10문항 · 30문항 (문항당 2점, 100점 만점) |
| 합격 기준 | 총점 60점 이상, 과목별 40% 미만이면 과락 |
| 응시료 | 50,000원 |
| 시행 | 연 4회 |

:::warn 접수 전에 꼭 다시 확인할 것
이 표는 2026년 11월 기준으로 정리했다. 회차별 날짜·응시료·세부 규정은 바뀔 수 있으니 접수 전에 데이터자격검정 홈페이지 공지를 확인하자. 최근 접수자가 크게 늘어 원하는 고사장이 빨리 마감되므로 접수 첫날 신청하는 편이 안전하다.
:::

## 과목별 비중과 전략

3과목이 30문항, 즉 60점이다. 3과목에서 무너지면 1·2과목을 만점 받아도 합격이 어렵다. 반대로 1·2과목은 각각 20점뿐이지만 40% 과락선(4문항)이 있어서 버리면 안 된다.

| 과목 | 성격 | 공부 방법 |
|---|---|---|
| 1과목 데이터 이해 | 개념·용어 암기 | 짝지어 외우기(DIKW, SECI, 위기요인-통제방안). 기출 반복이 가장 효율적 |
| 2과목 데이터 분석 기획 | 절차·프레임워크 암기 | 단계 순서와 각 단계 산출물을 표로 외우기. 사분면 문제 주의 |
| 3과목 데이터 분석 | 통계·머신러닝 이해 + R 출력 해석 | 공식은 "무엇을 무엇으로 나누는지"로 이해. R 결과표에서 p-value·계수 읽는 연습 |

## 4주 공부 순서 (비전공자 기준)

1. **1주차** — 이 교본 1~3장(1과목)을 읽고 각 장 끝 문제를 푼다. 틀린 용어는 노트에 짝으로 적는다.
2. **2주차** — 4~5장(2과목). 방법론 단계와 사분면은 손으로 그려 본다.
3. **3주차** — 6~9장(3과목). 통계는 7장을 두 번 읽고 8·9장으로 넘어간다. 혼동행렬 계산기로 지표 계산을 직접 해 본다.
4. **4주차** — 10장 모의 문제와 기출문제 3회분 이상. 틀린 문제의 장으로 돌아가 다시 읽는다.

:::tip 이 교본 쓰는 법
- 각 장 머리의 **이 장만 PDF로** 버튼을 누르면 그 장만 A4로 저장된다. 상단 **PDF로 저장**에서는 여러 장을 골라 한 파일로 만들 수 있다.
- 문제의 보기를 누르면 바로 채점되고 해설이 열린다. 인쇄할 때는 정답·해설을 넣을지 뺄지 고를 수 있다.
:::

# 1과목 · 데이터 이해 | 데이터의 이해

## 데이터의 정의와 유형

**데이터(Data)**는 추론과 추정의 근거가 되는 사실이다. 단순한 객체로서의 가치와 함께 다른 객체와의 상호관계 속에서 가치를 갖는다. 데이터는 **존재적 특성**(있는 그대로의 사실)과 **당위적 특성**(추론·예측·의사결정의 근거)을 함께 가진다.

| 구분 | 정성적 데이터 (Qualitative) | 정량적 데이터 (Quantitative) |
|---|---|---|
| 형태 | 언어, 문자 | 수치, 기호, 도형 |
| 예 | 회사 매출 증가에 대한 기사, SNS 글, 설문 주관식 응답 | 지역별 온도, 풍속, 강우량, 매출액 |
| 특징 | 저장·검색·분석에 많은 비용 | 정형화되어 저장·분석이 쉬움 |

정형 / 반정형 / 비정형으로도 나눈다.

| 구분 | 설명 | 예 |
|---|---|---|
| 정형 데이터 | 정해진 형식(스키마)으로 칼럼·행에 저장 | 관계형 DB 테이블, 엑셀, CSV |
| 반정형 데이터 | 형식은 있지만 값과 구조가 함께 들어 있음(메타데이터 포함) | XML, HTML, JSON, 로그 |
| 비정형 데이터 | 형식이 없음 | 텍스트 문서, 이미지, 음성, 동영상 |

## 암묵지와 형식지, SECI 모델

| 구분 | 암묵지 (Tacit Knowledge) | 형식지 (Explicit Knowledge) |
|---|---|---|
| 뜻 | 학습과 경험으로 개인에게 체화되어 있지만 겉으로 드러나지 않는 지식 | 문서·매뉴얼처럼 형상화되어 공유할 수 있는 지식 |
| 예 | 김장 김치 담그기 손맛, 자전거 타기 | 교과서, 매뉴얼, 비디오, DB |
| 특징 | 공유하기 어렵다 | 전달·공유가 쉽다 |

노나카 이쿠지로의 **SECI 모델**은 두 지식이 서로 바뀌며 조직의 지식이 커지는 과정이다.

| 단계 | 변환 | 설명 |
|---|---|---|
| 공통화 (Socialization) | 암묵지 → 암묵지 | 함께 일하며 경험을 공유 (도제식 교육) |
| 표출화 (Externalization) | 암묵지 → 형식지 | 개인의 노하우를 문서·매뉴얼로 만듦 |
| 연결화 (Combination) | 형식지 → 형식지 | 문서끼리 합쳐 새 지식 체계를 만듦 |
| 내면화 (Internalization) | 형식지 → 암묵지 | 매뉴얼을 읽고 익혀 자기 것으로 체화 |

:::exam
순서는 **공통화 → 표출화 → 연결화 → 내면화**(S-E-C-I). "형식지를 다른 형식지와 결합" = 연결화, "형식지를 개인이 체화" = 내면화를 바로 짝지을 수 있어야 한다.
:::

## DIKW 피라미드

데이터가 가공되면서 정보, 지식, 지혜로 올라간다.

:::fig dikw

| 단계 | 정의 | 예 |
|---|---|---|
| 데이터 (Data) | 다른 데이터와 상관관계가 없는 가공 전 객관적 사실 | A마트 볼펜 100원, B마트 200원 |
| 정보 (Information) | 데이터를 가공·처리해 관계 속에서 의미가 도출된 것 | A마트 볼펜이 더 싸다 |
| 지식 (Knowledge) | 정보를 구조화해 유의미한 정보를 분류·개인화한 것 | 상대적으로 저렴한 A마트에서 볼펜을 사야겠다 |
| 지혜 (Wisdom) | 지식의 축적과 아이디어가 결합된 창의적 산물 | A마트의 다른 상품도 B마트보다 쌀 것이다 |

## 데이터베이스의 정의와 특징

**데이터베이스(Database)**는 체계적으로 수집·축적하여 다양한 용도와 방법으로 이용할 수 있게 정리한 정보의 집합체다. 데이터베이스를 관리하는 소프트웨어를 **DBMS**(Database Management System)라 한다.

- 1950년대 미국에서 군비 상황을 집중 관리하려고 만든 "데이터의 기지(Data Base)"에서 유래.
- 1963년 미국 SDC 심포지엄에서 Database라는 용어가 공식 사용. 1970년대 초 유럽에서 "Database"라는 단일어로 정착.
- 국내 저작권법은 데이터베이스를 "소재를 체계적으로 배열 또는 구성한 편집물로서 개별적으로 그 소재에 접근하거나 검색할 수 있도록 한 것"으로 정의한다.

| 특징 | 설명 |
|---|---|
| 통합된 데이터 (Integrated) | 동일한 내용의 데이터가 중복되지 않는다 |
| 저장된 데이터 (Stored) | 컴퓨터가 접근할 수 있는 저장 매체에 저장된다 |
| 공용 데이터 (Shared) | 여러 사용자가 다양한 목적으로 함께 이용한다 |
| 변화되는 데이터 (Changeable) | 새 데이터 삽입, 삭제, 갱신으로 항상 변화하면서도 현재의 정확한 데이터를 유지한다 |

다른 측면에서 본 특징도 나온다.

- **정보의 축적 및 전달 측면**: 기계 가독성, 검색 가능성, 원격 조작성
- **정보 이용 측면**: 이용자의 정보 요구에 따라 원하는 정보를 정확하고 경제적으로 찾을 수 있다
- **정보 관리 측면**: 방대한 정보를 일정한 질서와 구조에 따라 정리·저장하고 검색·관리할 수 있어 체계적 관리가 가능
- **정보기술 발전 측면**: 정보처리, 검색·관리 소프트웨어, 관련 하드웨어, 네트워크 기술의 발전을 견인
- **경제·산업적 측면**: 다양한 정보를 필요에 따라 신속하게 공급해 경제·사회 전반의 효율을 높이는 인프라

### 데이터베이스 설계 절차

요구사항 분석 → **개념적 설계**(E-R 다이어그램, DBMS 독립적) → **논리적 설계**(테이블·키 정의, 정규화) → **물리적 설계**(저장 구조, 인덱스, 접근 방법)

## 기업 내부 데이터베이스 활용

| 시스템 | 설명 |
|---|---|
| OLTP (On-Line Transaction Processing) | 호스트 컴퓨터와 단말기가 온라인으로 연결되어 주문·결제 같은 거래를 즉시 처리. 데이터 갱신 위주 |
| OLAP (On-Line Analytical Processing) | 다차원 데이터를 사용자가 직접 대화식으로 분석. 데이터 조회·분석 위주 |
| ERP (Enterprise Resource Planning) | 인사·재무·생산 등 기업 전 부문 자원을 통합 관리하는 시스템 |
| CRM (Customer Relationship Management) | 고객 데이터를 바탕으로 고객과의 관계를 관리. 고객 확보·유지, 수익성 향상 |
| SCM (Supply Chain Management) | 원재료 조달부터 생산·유통·판매까지 공급망 전체를 관리 |
| BI (Business Intelligence) | 데이터를 정리·분석해 의사결정에 쓰는 리포트 중심 도구 |
| BA (Business Analytics) | 경영 의사결정을 위해 통계적·수학적 분석으로 미래를 예측하는 데 초점 |
| KMS (Knowledge Management System) | 조직의 지식을 축적·공유하는 지식관리 시스템 |
| RTE (Real-Time Enterprise) | 회사의 주요 경영정보를 통합 관리하는 실시간 기업 |

| 구분 | OLTP | OLAP |
|---|---|---|
| 데이터 구조 | 복잡 (정규화) | 단순 (비즈니스 사용자 관점) |
| 데이터 갱신 | 동적·순간적 | 정적·주기적 |
| 응답 시간 | 수 초 이내 | 수 초 ~ 수 분 |
| 데이터 범위 | 수십 ~ 수백 일 | 오랜 기간 저장 |
| 성격 | 정규적인 핵심 데이터 | 비정규적 읽기 전용 |

### 산업 분야별 활용

- **제조**: ERP·SCM 도입, 2000년대 이후 CRM과 연계, 실시간 기업(RTE) 지향
- **금융**: EAI(전사적 애플리케이션 통합), ERP, e-CRM, 데이터 웨어하우스 기반 분석
- **유통**: CRM, SCM, 전자태그(RFID) 활용

### 사회기반구조로서의 데이터베이스

- **물류**: CVO(화물운송정보), PORT-MIS(항만운영정보), KROIS(철도운영정보)
- **지리**: GIS(지리정보시스템), LBS(위치기반서비스), SIS(공간정보서비스)
- **교통**: ITS(지능형교통시스템)

- **교육**: NEIS(교육행정정보시스템)

## 데이터 웨어하우스와 데이터 마트

**데이터 웨어하우스(DW)**는 ETL로 여러 원천 데이터를 모아 의사결정에 쓰도록 통합한 저장소다.

| 특징 | 설명 |
|---|---|
| 주제 지향성 (Subject Oriented) | 업무 처리(트랜잭션)가 아니라 고객·제품 같은 주제 중심으로 구성 |
| 통합성 (Integrated) | 여러 시스템의 데이터를 일관된 형식으로 통합 |
| 시계열성 (Time Variant) | 과거부터 현재까지의 이력 데이터를 보관 |
| 비휘발성 (Non-Volatile) | 적재된 데이터는 읽기 전용, 갱신·삭제되지 않음 |

- **ETL**: 추출(Extract) → 변환(Transform) → 적재(Load)
- **데이터 마트(Data Mart)**: DW의 일부를 특정 부서·주제용으로 떼어낸 작은 저장소
- **데이터 레이크(Data Lake)**: 정형·반정형·비정형 데이터를 원형 그대로 저장하는 대용량 저장소
- **ODS(Operational Data Store)**: DW에 넣기 전 운영 데이터를 통합해 두는 임시 저장소

# 1과목 · 데이터 이해 | 데이터의 가치와 미래

## 빅데이터의 정의

빅데이터는 보는 관점에 따라 정의가 다르다.

| 관점 | 정의 |
|---|---|
| 좁은 범위 (데이터 자체) | 기존 데이터베이스 관리 도구로 수집·저장·관리·분석할 수 있는 역량을 넘어서는 대량의 정형·비정형 데이터 |
| 중간 범위 (+ 처리·분석 기술) | 데이터 + 이를 처리·분석하는 기술 |
| 넓은 범위 (+ 인재·조직) | 데이터 + 기술 + 이를 활용하는 인재와 조직 변화까지 포함 |

가트너(Gartner)의 **3V**가 가장 유명하다.

| 요소 | 뜻 |
|---|---|
| Volume (규모) | 데이터 양이 매우 많다 |
| Variety (다양성) | 정형·반정형·비정형 등 형태가 다양하다 |
| Velocity (속도) | 생성·처리 속도가 빠르다 (실시간) |
| + Value (가치) | 4V. 분석으로 비즈니스 가치를 만든다 |
| + Veracity (정확성) | 데이터의 신뢰성·품질 |

- **맥킨지**: 일반적인 DB 소프트웨어로 저장·관리·분석할 수 있는 범위를 초과하는 규모의 데이터
- **IDC**: 다양한 종류의 대규모 데이터로부터 저렴한 비용으로 가치를 추출하고, 초고속 수집·발굴·분석을 지원하는 차세대 기술과 아키텍처

## 빅데이터의 출현 배경

- **산업계**: 고객 데이터가 쌓이면서 그 안의 가치를 발굴하려는 양질 전환 현상
- **학계**: 인간 게놈 프로젝트, 천문학, 물리학처럼 거대 데이터를 다루는 학문 분야 등장
- **기술 발전**: 디지털화, 저장 기술 발전과 가격 하락, 인터넷 확산, 모바일, 클라우드 컴퓨팅, 하둡 같은 분산처리 기술

## 빅데이터의 기능 (비유)

| 비유 | 의미 |
|---|---|
| 산업혁명의 석탄·철 | 산업 전반의 생산성을 크게 높이고 혁명적 변화를 가져온다 |
| 21세기의 원유 | 각종 비즈니스·공공기관 대국민 서비스의 생산성을 높이고 새로운 범주의 산업을 만든다 |
| 렌즈 | 현미경이 생물학을 바꾼 것처럼 데이터가 산업에 영향을 미친다 (구글 Ngram Viewer) |
| 플랫폼 | 공동 활용 목적으로 구축된 유무형 구조물. 다양한 서드파티 비즈니스의 기반 (페이스북 API) |

## 빅데이터가 만들어 내는 본질적 변화

| 이전 | → | 이후 | 설명 |
|---|---|---|---|
| 사전처리 | → | **사후처리** | 필요한 정보만 미리 가공해 모으던 방식에서, 가능한 한 많이 모아 나중에 다양하게 조합 |
| 표본조사 | → | **전수조사** | 데이터 처리 비용이 낮아져 전체를 분석 |
| 질 | → | **양** | 데이터가 많으면 일부 오류 데이터의 영향이 줄어든다 |
| 인과관계 | → | **상관관계** | 이유를 몰라도 상관관계로 예측·의사결정 (실시간 대응) |

## 빅데이터 가치 산정이 어려운 이유

1. **데이터 활용 방식** — 재사용·재조합·다목적 개발이 일반화되어 누가 어디에 활용할지 알 수 없다
2. **새로운 가치 창출** — 기존에 없던 가치를 만들어 내므로 측정 기준이 없다
3. **분석 기술 발전** — 지금은 가치 없는 데이터도 새 분석 기법이 나오면 가치가 생긴다

## 빅데이터 활용 기본 테크닉 7가지

| 기법 | 설명 | 예 |
|---|---|---|
| 연관 규칙 학습 | 변인들 간에 주목할 만한 상관관계가 있는지 찾음 | 커피를 사는 사람이 탄산음료도 많이 사는가? |
| 유형 분석 (분류) | 문서·조직을 분류하거나 새 사례가 어느 그룹에 속하는지 판단 | 이 사용자는 어떤 특성을 가진 집단에 속하는가? |
| 유전 알고리즘 | 최적화가 필요한 문제의 해결책을 자연선택·돌연변이처럼 점진적으로 진화시킴 | 최대 시청률을 얻으려면 어떤 프로그램을 어느 시간대에 방송해야 하나? 응급실 의사 배치 |
| 기계 학습 | 훈련 데이터로 학습한 알려진 특성을 활용해 예측 | 시청 기록으로 볼 만한 영화 추천 |
| 회귀 분석 | 독립변수를 조작하며 종속변수가 어떻게 변하는지 보고 관계를 파악 | 구매자 나이가 구매 차량 타입에 영향을 주는가? |
| 감정 분석 | 특정 주제에 대한 글쓴이의 감정을 분석 | 새 환불 정책에 대한 고객 평가는? |
| 소셜 네트워크 분석 | 사용자 간 관계를 분석해 영향력 있는 사람(인플루언서)을 찾음 | 고객 간 소셜 관계는 어떤가? |

:::exam
보기에 예시 문장을 주고 기법을 고르게 한다. **"최적화"·"배치"·"편성"이 보이면 유전 알고리즘**, "~끼리 같이 산다"는 연관 규칙, "어느 집단에 속하나"는 유형 분석이다.
:::

## 빅데이터 시대의 위기 요인과 통제 방안

| 위기 요인 | 내용 | 통제 방안 |
|---|---|---|
| 사생활 침해 | 특정 목적으로 수집된 정보가 다른 목적으로 2차·3차 활용되며 사생활을 침해 | 개인정보 제공자의 **동의제 → 사용자 책임제**로 전환 |
| 책임 원칙 훼손 | 예측 알고리즘 때문에 아직 하지 않은 행동으로 처벌받을 수 있음 (영화 마이너리티 리포트) | **결과 기반 책임 원칙** 고수 (행동한 결과로만 책임) |
| 데이터 오용 | 데이터가 과거에 기반하므로 미래 예측이 틀릴 수 있고, 잘못된 지표 사용 | **알고리즘 접근 허용**, 알고리즘을 해석·검증하는 전문가 **알고리즈미스트** |

## 빅데이터 활용의 3요소와 미래

| 요소 | 내용 | 미래 변화 |
|---|---|---|
| 자원 (데이터) | 빅데이터 | 모든 것의 데이터화 (Datafication), IoT |
| 기술 | 빅데이터 플랫폼, 인공지능 | 진화하는 알고리즘, 인공지능 |
| 인력 | 데이터 사이언티스트, 알고리즈미스트 | 데이터 사이언티스트·알고리즈미스트 수요 증가 |

빅데이터가 가치를 만드는 방식: **투명성 제고**, **시뮬레이션을 통한 수요 포착**(환경 탐색), **고객 세분화와 맞춤 서비스**, **알고리즘을 활용한 의사결정 보조 또는 대체**, **비즈니스 모델·제품·서비스 혁신**.

빅데이터가 바꾼 영역별 효과

- **기업**: 혁신, 경쟁력 제고, 생산성 향상
- **정부**: 환경 탐색, 상황 분석, 미래 대응
- **개인**: 목적에 따른 활용 (스마트 기기, 맞춤 서비스)

# 1과목 · 데이터 이해 | 데이터 사이언스와 전략 인사이트

## 빅데이터 분석에 대한 오해

- **빅데이터 회의론**: 과거 CRM처럼 "솔루션만 사면 된다"는 공포 마케팅, 막대한 투자 대비 효과 미흡, 분석 사례가 사실 기존 분석과 다르지 않음
- **데이터 양보다 시각이 중요**: 중요한 것은 데이터의 크기가 아니라 비즈니스 핵심에 대한 객관적 인사이트를 찾는 것
- **전략적 통찰이 없는 분석의 함정**: 경쟁사를 따라 분석만 하는 일차적 분석은 효과가 제한적. 사업 성과를 내려면 전략적 통찰이 필요하다

### 일차적 분석 vs 전략 도출 가치 기반 분석

| 구분 | 일차적 분석 | 전략 도출을 위한 가치 기반 분석 |
|---|---|---|
| 목적 | 부서 단위 업무 개선 (비용 절감, 효율) | 사업 성과를 좌우하는 핵심 질문에 답 |
| 범위 | 해당 부서·업무 | 비즈니스 전체, 경쟁 환경, 고객 |
| 예 | 금융: 신용 점수 / 소매: 재고 보충 / 제조: 맞춤형 상품 개발 | 새로운 기회 발굴, 사업 모델 변화 |

산업별 일차적 분석 예

| 산업 | 일차적 분석 애플리케이션 |
|---|---|
| 금융 서비스 | 신용점수 산정, 사기 탐지, 가격 책정, 프로그램 트레이딩, 클레임 분석, 고객 수익성 분석 |
| 소매업 | 판촉, 매대 관리, 수요 예측, 재고 보충, 가격·제조 최적화 |
| 제조업 | 맞춤형 상품 개발, 신상품 개발 |
| 에너지 | 트레이딩, 공급·수요 예측 |
| 온라인 | 고객 추천, 사이트 설계 |
| 병원 | 약품 거래, 예비 진단, 질병 관리 |
| 정부 | 사기 탐지, 사례 관리, 범죄 방지, 수익 최적화 |

## 데이터 사이언스

**데이터 사이언스(Data Science)**는 데이터로부터 의미 있는 정보를 추출해 내는 학문이다. 통계학이 정형 데이터 분석에 집중하는 것과 달리, 정형·반정형·비정형을 모두 다루고, 분석뿐 아니라 이를 효과적으로 구현·전달하는 과정까지 포함한다.

:::warn 통계학·데이터마이닝과의 차이
- 통계학: 정형 데이터, 분석 자체에 초점
- 데이터마이닝: 대량 데이터에서 패턴을 찾는 분석 기법
- 데이터 사이언스: 비정형까지 포함, 분석 + 구현 + 전달(커뮤니케이션)까지 포괄하는 **더 넓은 개념**
:::

### 데이터 사이언스의 구성 요소

| 영역 | 내용 |
|---|---|
| Analytics (분석) | 수학, 확률 모델, 머신러닝, 분석학, 패턴 인식, 데이터 마이닝, 불확실성 모델링 |
| IT (데이터 관리) | 시그널 프로세싱, 프로그래밍, 데이터 엔지니어링, 데이터 웨어하우징, 고성능 컴퓨팅 |
| 비즈니스 분석 | 커뮤니케이션, 프레젠테이션, 스토리텔링, 시각화 |

## 데이터 사이언티스트의 역량

| 하드 스킬 (Hard Skill) | 소프트 스킬 (Soft Skill) |
|---|---|
| 빅데이터에 대한 이론적 지식: 관련 기법 이해와 방법론 습득 | 통찰력 있는 분석: 창의적 사고, 호기심, 논리적 비판 |
| 분석 기술에 대한 숙련: 최적 분석 설계와 노하우 축적 | 설득력 있는 전달: 스토리텔링, 비주얼라이제이션 |
| | 다분야 간 협력: 커뮤니케이션 |

- **가트너**가 제시한 데이터 사이언티스트 요구 역량: 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬
- 데이터 사이언티스트는 정량 분석만이 아니라 **소프트 스킬**도 중요하다. 시험에서 "하드 스킬만 중요하다"류의 보기는 틀린 보기다.

## 가치 패러다임의 변화

| 단계 | 핵심 | 설명 |
|---|---|---|
| 디지털화 (Digitalization) | 아날로그 → 디지털 | 운영체제, 워드프로세서처럼 디지털 정보를 만드는 것이 가치 |
| 연결 (Connection) | 디지털 정보의 연결 | 구글 검색, 네이버처럼 정보를 효과적으로 연결하는 것이 가치 |
| 에이전시 (Agency) | 연결의 관리 | 사물인터넷처럼 복잡한 연결을 효과적·효율적으로 관리해 주는 것이 가치 |

## 인문학 열풍의 이유

1. **컨버전스 → 디버전스**: 단순 세계화에서 복잡한 세계화로 변화
2. **생산 → 서비스**: 비즈니스 중심이 제품 생산에서 서비스로 이동
3. **생산 → 시장 창조**: 공급자 중심 기술 경쟁에서 무형자산 경쟁으로 변화

데이터 사이언스는 결국 사람과 사회를 이해해야 하므로 인문학적 사고(가정의 타당성, 질문하는 힘)가 필요하다.

## 데이터 분석 모델의 한계

- **모델은 현실 세계를 단순화한 것**이다. 가정이 틀리면 결과도 틀린다 (예: 2008년 금융위기 때 위험 모델)
- 분석가는 모델의 가정과 범위를 이해하고, 결과를 해석할 때 한계를 함께 고려해야 한다
- 정량적 분석이라도 **해석에는 주관이 개입**된다

# 2과목 · 데이터 분석 기획 | 데이터 분석 기획의 이해

## 분석 기획이란

**분석 기획**은 실제 분석을 수행하기 전에 무엇을(What), 어떻게(How) 분석할지 계획하는 작업이다. 분석가는 **수학·통계 지식**, **정보기술(IT, 프로그래밍, 데이터 관리)**, **해당 비즈니스 도메인 지식**을 고루 갖추고 프로젝트 관리 역량과 리더십을 발휘해야 한다.

## 분석 주제 유형 4가지

분석의 **대상(What)**을 아는지, 분석의 **방법(How)**을 아는지에 따라 나눈다.

| | 분석 대상 Known | 분석 대상 Un-Known |
|---|---|---|
| **분석 방법 Known** | 최적화 (Optimization) | 통찰 (Insight) |
| **분석 방법 Un-Known** | 솔루션 (Solution) | 발견 (Discovery) |

- **최적화**: 문제도 알고 방법도 안다 → 개선을 통해 최적화
- **솔루션**: 문제는 아는데 방법을 모른다 → 해법을 찾는다
- **통찰**: 방법은 아는데 대상이 명확하지 않다 → 기존 분석 방식을 활용해 새로운 통찰 도출
- **발견**: 둘 다 모른다 → 새로운 분석 대상 자체를 발견

## 목표 시점별 분석 기획

| 구분 | 과제 중심적 접근 (당면 과제) | 마스터 플랜 접근 (지속적 분석 내재화) |
|---|---|---|
| 기간 | 단기 | 중장기 |
| 1차 목표 | Speed & Test | Accuracy & Deploy |
| 과제 유형 | Quick-Win | Long Term View |
| 접근 방식 | Problem Solving | Problem Definition |

의미 있는 분석을 위해서는 두 접근을 **융합**해서 쓴다. Quick-Win으로 빨리 성과를 보여주고 장기 마스터 플랜으로 이어간다.

## 분석 기획 시 고려사항

1. **가용 데이터(Available Data)** — 분석을 위한 데이터 확보가 우선. 데이터 유형(정형·반정형·비정형)에 따라 적용 솔루션과 분석 방법이 달라진다
2. **적절한 유스케이스(Proper Use-Case) 탐색** — 유사 분석 시나리오와 솔루션이 있다면 최대한 활용
3. **분석 수행 시 장애 요소 고려** — 정확도를 올리기 위한 기간·투입 자원 증가, 분석 결과를 사용자가 쉽게 이해할 수 있는지, 일회성이 아닌 조직 역량으로 내재화할 수 있는지(변화관리)

## 분석 방법론

방법론은 **상세한 절차(Procedures)**, **방법(Methods)**, **도구와 기법(Tools & Techniques)**, **템플릿과 산출물(Templates & Outputs)**로 구성된다. 개인의 암묵지가 **형식화 → 체계화 → 내재화**되면서 방법론이 만들어진다.

합리적 의사결정을 막는 장애 요소: **고정관념(Stereotype)**, **편향된 생각(Bias)**, **프레이밍 효과(Framing Effect)** — 같은 사안도 표현 방식에 따라 판단이 달라지는 현상.

### 방법론의 적용 모델

| 모델 | 특징 |
|---|---|
| 폭포수 모델 (Waterfall) | 단계를 순차적으로 진행. 이전 단계가 완료되어야 다음 단계로. 문제가 발견되면 피드백 |
| 프로토타입 모델 (Prototype) | 일부를 먼저 개발(시제품)해 사용자에게 보여주고 피드백 받아 개선. 고객 요구가 불명확할 때 |
| 나선형 모델 (Spiral) | 반복을 통해 점증적으로 개발. 처음 시도하는 프로젝트에 유리하지만 관리 체계가 없으면 복잡도가 상승 |

### 계층적 프로세스 모델

방법론은 보통 **단계(Phase) → 태스크(Task) → 스텝(Step)**의 3계층이다.

- 단계: 프로세스 그룹. 완성된 단계별 산출물이 생성되며 기준선(Baseline)으로 설정·관리
- 태스크: 단계를 구성하는 단위 활동. 물리적·논리적 단위로 품질 검토 항목이 된다
- 스텝: WBS의 워크패키지에 해당. 입력 자료(Input), 처리 및 도구(Process & Tool), 출력 자료(Output)로 구성된 단위 프로세스

## KDD 분석 방법론

1996년 Fayyad가 정리한 데이터베이스 속 지식 발견(Knowledge Discovery in Databases) 절차. 데이터에서 패턴을 찾는 데이터마이닝 프로세스다.

1. **데이터셋 선택(Selection)** — 비즈니스 도메인 이해와 목표 설정, 분석 대상 데이터셋 선택
2. **데이터 전처리(Preprocessing)** — 잡음(Noise), 이상치(Outlier), 결측치(Missing Value) 식별 및 처리
3. **데이터 변환(Transformation)** — 변수 선택, 차원 축소, 학습용·검증용 데이터 분리
4. **데이터 마이닝(Data Mining)** — 분석 목적에 맞는 기법·알고리즘 선택, 패턴 탐색, 분류·예측
5. **해석과 평가(Interpretation/Evaluation)** — 결과를 해석·평가하고 발견된 지식을 업무에 활용

## CRISP-DM 분석 방법론

1996년 유럽연합 ESPRIT 프로젝트에서 시작한 방법론. **4레벨, 6단계**로 구성된다.

- 4레벨: **단계(Phases) → 일반화 태스크(Generic Tasks) → 세분화 태스크(Specialized Tasks) → 프로세스 실행(Process Instances)**
- 6단계는 한 방향으로만 흐르지 않고 **단계 간 피드백**으로 완성도를 높인다.

:::fig crisp

| 단계 | 주요 태스크 |
|---|---|
| 1. 업무 이해 (Business Understanding) | 업무 목적 파악, 상황 파악, 데이터 마이닝 목표 설정, 프로젝트 계획 수립 |
| 2. 데이터 이해 (Data Understanding) | 초기 데이터 수집, 데이터 기술 분석, 데이터 탐색, 데이터 품질 확인 |
| 3. 데이터 준비 (Data Preparation) | 분석용 데이터셋 선택, 데이터 정제, 분석용 데이터셋 편성, 데이터 통합, 데이터 포매팅 |
| 4. 모델링 (Modeling) | 모델링 기법 선택, 모델 테스트 계획 설계, 모델 작성, 모델 평가 |
| 5. 평가 (Evaluation) | 분석 결과 평가, 모델링 과정 평가, 모델 적용성 평가 |
| 6. 전개 (Deployment) | 전개 계획 수립, 모니터링과 유지보수 계획 수립, 프로젝트 종료 보고서 작성, 프로젝트 리뷰 |

:::warn 헷갈리는 포인트
- 모델링 단계의 "모델 평가"와 평가 단계의 "분석 결과 평가"는 다르다. 모델링 단계는 **모델 자체의 성능**, 평가 단계는 **비즈니스 목표 달성 여부**를 본다.
- 데이터 정제·통합은 **데이터 준비** 단계다. 데이터 품질 확인은 **데이터 이해** 단계다.
:::

### KDD와 CRISP-DM 비교

| KDD | CRISP-DM |
|---|---|
| 분석 대상 비즈니스 이해 | 업무 이해 |
| 데이터셋 선택 + 데이터 전처리 | 데이터 이해 |
| 데이터 변환 | 데이터 준비 |
| 데이터 마이닝 | 모델링 |
| 데이터 마이닝 결과 평가 | 평가 |
| 데이터 마이닝 활용 | 전개 |

## 빅데이터 분석 방법론 (5단계)

국내에서 정리된 빅데이터 분석 방법론. 단계별 태스크와 산출물을 외워 두자.

| 단계 | 태스크 | 주요 내용·산출물 |
|---|---|---|
| 1. 분석 기획 (Planning) | 비즈니스 이해 및 범위 설정 | 프로젝트 범위 정의서 **SOW**(Statement Of Work) |
| | 프로젝트 정의 및 계획 수립 | 모델 운영 이미지·평가 기준 설정, **WBS** 작성 |
| | 프로젝트 위험계획 수립 | 위험 식별, 대응 방법: **회피(Avoid), 전이(Transfer), 완화(Mitigate), 수용(Accept)** |
| 2. 데이터 준비 (Preparing) | 필요 데이터 정의 | 데이터 정의서 |
| | 데이터 스토어 설계 | 정형·비정형 데이터 스토어 설계 |
| | 데이터 수집 및 정합성 점검 | 크롤링, ETL, API, 정합성 점검 |
| 3. 데이터 분석 (Analyzing) | 분석용 데이터 준비 | 비즈니스 룰 확인, 분석용 데이터셋 준비 |
| | 텍스트 분석 | 텍스트 데이터 확인·추출, 텍스트 분석 |
| | 탐색적 분석 (EDA) | 탐색적 데이터 분석, 데이터 시각화 |
| | 모델링 | 데이터 분할, 데이터 모델링, 모델 적용 및 운영 방안 |
| | 모델 평가 및 검증 | 모델 평가, 모델 검증 |
| 4. 시스템 구현 (Developing) | 설계 및 구현 | 시스템 분석 및 설계, 시스템 구현 |
| | 시스템 테스트 및 운영 | 시스템 테스트, 시스템 운영 계획 |
| 5. 평가 및 전개 (Deploying) | 모델 발전계획 수립 | 모델 발전 계획 |
| | 프로젝트 평가 및 보고 | 프로젝트 성과 평가, 프로젝트 종료 |

:::exam
- 데이터 분석 단계에서 **분석용 데이터가 부족하면 데이터 준비 단계로 되돌아가는 피드백**이 있다.
- 위험 대응 4가지(회피·전이·완화·수용)는 분석 기획 단계의 위험계획 수립에서 다룬다.
- **SOW**는 분석 기획 단계 산출물이다.
:::

## 분석 과제 발굴: 하향식 접근법

**하향식(Top Down)**은 문제가 주어지고 해법을 찾기 위해 각 과정을 체계적으로 단계화해 수행하는 방식이다.

1. **문제 탐색(Problem Discovery)**
2. **문제 정의(Problem Definition)**
3. **해결방안 탐색(Solution Search)**
4. **타당성 검토(Feasibility Study)**

### 1) 문제 탐색

**비즈니스 모델 캔버스**의 9블록을 단순화해 5개 영역으로 문제를 찾는다.

| 영역 | 내용 |
|---|---|
| 업무 (Operation) | 제품·서비스를 생산하기 위해 운영하는 내부 프로세스와 리소스 |
| 제품 (Product) | 생산·제공하는 제품과 서비스 개선 |
| 고객 (Customer) | 고객과 고객에게 제품을 전달하는 채널 |
| 규제와 감사 (Audit & Regulation) | 제품 생산·전달 과정에서 발생하는 규제와 보안 |
| 지원 인프라 (IT & Human Resource) | 분석을 수행하는 시스템 영역과 운영·관리하는 인력 |

**분석 기회 발굴의 범위 확장**: 현재 사업을 넘어 환경과 경쟁 구도까지 본다.

| 관점 | 세부 영역 |
|---|---|
| 거시적 관점 (STEEP) | 사회(Social), 기술(Technological), 경제(Economic), 환경(Environmental), 정치(Political) |
| 경쟁자 확대 관점 | 대체재(Substitute), 경쟁자(Competitor), 신규 진입자(New Entrant) |
| 시장 니즈 탐색 관점 | 고객(Customer), 채널(Channel), 영향자(Influencer) |
| 역량의 재해석 관점 | 내부 역량(Competency), 파트너와 네트워크(Partners & Network) |

**외부 참조 모델 기반 문제 탐색**: 유사·동종 업계의 사례를 벤치마킹해 분석 기회를 빠르게 찾는다. 이렇게 찾은 분석 기회를 **분석 유스케이스**로 정의한다.

### 2) 문제 정의

비즈니스 문제를 **데이터의 문제로 변환**한다. 예: "고객 이탈이 늘었다"(비즈니스 문제) → "고객의 이탈 가능성을 예측하는 모델을 만든다"(데이터 분석 문제). 최종 사용자 관점에서 정의해야 한다.

### 3) 해결방안 탐색

| | 분석 역량 (Who) 확보 | 분석 역량 미확보 |
|---|---|---|
| **분석 기법·시스템 (How) 기존 시스템** | 기존 시스템 개선 활용 | 교육 및 채용을 통한 역량 확보 |
| **신규 도입** | 시스템 고도화 | 전문 업체 Sourcing (아웃소싱) |

### 4) 타당성 검토

- **경제적 타당성**: 비용 대비 편익 분석. 비용 = 데이터·시스템·인력·유지보수, 편익 = 실질적 비용 절감, 추가 매출, 수익
- **데이터 및 기술적 타당성**: 데이터 존재 여부, 분석 시스템 환경, 분석 역량

## 분석 과제 발굴: 상향식 접근법

**상향식(Bottom Up)**은 문제 정의 자체가 어려울 때, 데이터를 먼저 보고 그 안에서 통찰을 찾아 문제를 정의하는 방식이다.

- **디자인 사고(Design Thinking)**: 문제의 본질을 이해하는 **Why**에서 시작해 **What**을 찾는다. **발산(Diverge)**과 **수렴(Converge)**을 반복
- 주로 **비지도 학습(Unsupervised Learning)** 방법을 쓴다. 목표값 없이 데이터 자체의 결합·연관성·유사성을 찾음 (군집, 연관규칙, 기술통계)
- 지도 학습은 명확한 목적이 있는 하향식에 가깝다
- **시행착오를 통한 문제 해결 (프로토타이핑)**: 일단 분석을 시도하고 결과를 보며 반복 개선. 순서는 **가설 생성 → 디자인에 대한 실험 → 실제 환경에서 테스트 → 테스트 결과에서 통찰 도출 및 가설 확인**
- 프로토타이핑이 필요한 이유: 문제에 대한 인식 수준이 낮을 때, 필요 데이터 존재 여부가 불확실할 때, 데이터 사용 목적이 가변적일 때

:::tip 하향식 vs 상향식
- 하향식: 문제가 명확하다 → 해법을 찾는다 → **Solution**을 향해
- 상향식: 문제가 불명확하다 → 데이터에서 문제를 찾는다 → **Discovery**를 향해
- 실제 현장에서는 둘을 반복적으로 섞어 쓴다 (발산 단계는 상향식, 수렴 단계는 하향식).
:::

## 분석 프로젝트 관리

분석 프로젝트는 일반 IT 프로젝트와 달리 데이터와 분석 특성 때문에 추가로 관리할 영역이 있다.

| 영역 | 내용 |
|---|---|
| Data Size | 분석할 데이터의 양 |
| Data Complexity | 비정형 데이터, 여러 시스템에 흩어진 원천 데이터 통합의 복잡도 |
| Speed | 분석 결과가 필요한 시점, 실시간 처리 여부 |
| Analytic Complexity | 분석 모델의 정확도와 복잡도는 트레이드오프. 해석 가능하면서 정확한 모델 |
| Accuracy & Precision | 정확도(실제값과 차이) vs 정밀도(반복 시 편차). **둘은 트레이드오프**인 경우가 많다 |

- 분석가는 **데이터 영역과 비즈니스 영역의 중간**에서 현황을 이해하고 분석 모델을 통한 조율자 역할을 한다.
- 분석 프로젝트는 도출된 결과의 재해석으로 지속적인 반복·정교화가 일어나므로 **프로토타이핑 방식의 애자일(Agile)** 관리 방식도 고려한다.

**프로젝트 관리 지식체계 (KS A ISO 21500) 10개 주제 그룹**: 통합, 이해관계자, 범위, 자원, 시간, 원가, 리스크, 품질, 조달, 의사소통

> 정답 3 | 분석 모델이 정교해질수록 해석이 어려워지는 문제는 Analytic Complexity 영역이다.

# 2과목 · 데이터 분석 기획 | 분석 마스터 플랜과 거버넌스

## 분석 마스터 플랜 수립 프레임워크

마스터 플랜은 중장기적으로 분석 과제를 어떤 순서로, 어떤 범위로 적용할지 정하는 계획이다.

| 단계 | 고려 요소 | 결과 |
|---|---|---|
| 우선순위 평가 | **전략적 중요도**, **비즈니스 성과·ROI**, **실행 용이성** | 적용 우선순위 설정 |
| 적용 범위·방식 | **업무 내재화 적용 수준**, **분석 데이터 적용 수준**, **기술 적용 수준** | 분석 구현 로드맵 수립 |

### ROI 관점의 우선순위 평가

빅데이터의 4V를 ROI로 바꿔 생각한다.

| 구분 | 요소 | 평가 기준 |
|---|---|---|
| 투자 비용 (Investment) | **Volume, Variety, Velocity** (3V) | **난이도** — 데이터 획득·저장·처리 비용 |
| 비즈니스 효과 (Return) | **Value** | **시급성** — 전략적 중요도, 목표 가치 |

### 포트폴리오 사분면 분석

가로축을 **난이도**, 세로축을 **시급성**으로 두고 과제를 배치한다.

| | 난이도 어려움 (Difficult) | 난이도 쉬움 (Easy) |
|---|---|---|
| **시급성 현재** | 1사분면 — 시급하지만 지금 바로 하기 어려움 | **3사분면 — 가장 먼저 수행** |
| **시급성 미래** | 2사분면 — 가장 나중 | 4사분면 — 시급하진 않지만 쉬움 |

- **시급성**이 가장 중요한 기준일 때 우선순위: **3 → 4 → 2**
- **난이도**가 가장 중요한 기준일 때 우선순위: **3 → 1 → 2**
- 1사분면 과제는 데이터 양·특성·분석 범위를 조정하면(난이도를 낮추면) 3사분면으로 옮겨 바로 할 수 있다

:::exam
사분면 번호와 위치를 그림으로 외워야 한다. 3사분면이 항상 1순위, 2사분면이 항상 마지막. 가운데 순서만 "시급성 → 4", "난이도 → 1"로 갈린다.
:::

## 이행 계획 수립

- **로드맵 수립**: 데이터 분석 체계 **도입** → 데이터 분석 **유효성 검증** → 데이터 분석 **확산 및 고도화**의 단계로 구성하고 단계별 추진 목표·과제·내용을 정한다
- **세부 이행 계획**: 데이터 수집·확보와 분석 단계를 반복하는 **반복적 정련(Iterative Refinement)** 방식. 전체는 폭포수 방식으로 가되, 데이터 수집과 모델링 단계는 반복적으로 수행하는 **혼합형**을 많이 쓴다

## 분석 거버넌스 체계

**분석 거버넌스**는 기업이 분석을 조직 문화로 정착시키고 지속적으로 고도화하기 위한 관리 체계다. 구성 요소 5가지:

| 구성 요소 | 내용 |
|---|---|
| Organization (조직) | 분석 기획·관리·수행 조직 |
| Process (프로세스) | 과제 기획·운영 프로세스 |
| System (시스템) | 분석 관련 IT 시스템과 프로그램 |
| Data (데이터) | 데이터 거버넌스 |
| Human Resource (인력) | 분석 관련 교육과 마인드 육성 체계 |

## 분석 준비도와 분석 성숙도

### 분석 준비도 (Readiness)

조직의 분석 수준을 진단하는 프레임워크. 6개 영역을 평가한다.

| 영역 | 예 |
|---|---|
| 분석 업무 파악 | 발생한 사실 분석, 예측 분석, 시뮬레이션, 최적화 업무 |
| 인력 및 조직 | 분석 전문가 직무 존재, 교육 훈련, 관리자 기본 분석 능력, 전사 총괄 조직 |
| 분석 기법 | 업무별 적합한 분석 기법, 분석 기법 라이브러리, 효과성 평가 |
| 분석 데이터 | 충분성·신뢰성·적시성, 비구조적 데이터 관리, 외부 데이터 활용, 기준 데이터 관리(MDM) |
| 분석 문화 | 사실에 근거한 의사결정, 관리자의 데이터 중시, 회의 등에서 데이터 활용 |
| IT 인프라 | 운영 시스템 데이터 통합, EAI·ETL, 실시간 데이터 처리, 분석 환경(비주얼 분석, 빅데이터 분석) |

### 분석 성숙도 (Maturity)

소프트웨어 공학의 **CMMI** 모델을 기반으로 **비즈니스 부문, 조직·역량 부문, IT 부문**을 4단계로 평가한다.

| 단계 | 설명 | 비즈니스 부문 | IT 부문 |
|---|---|---|---|
| 도입 | 분석을 시작해 환경과 시스템을 구축 | 실적 분석 및 통계, 정기 보고 수행 | 데이터 웨어하우스, 데이터 마트, ETL/EAI, OLAP |
| 활용 | 분석 결과를 실제 업무에 적용 | 미래 결과 예측, 시뮬레이션 | 실시간 대시보드, 통계 분석 환경 |
| 확산 | 전사 차원에서 분석을 관리하고 공유 | 전사 성과 실시간 분석, 분석 규칙 관리 | 빅데이터 관리 환경, 시뮬레이션·최적화, 비주얼 분석 |
| 최적화 | 분석을 진화시켜 혁신과 성과 향상에 기여 | 외부 환경 분석 활용, 최적화 업무 적용, 실시간 분석 | 분석 협업 환경, 분석 Sandbox, 프로세스 내재화 |

### 준비도·성숙도 사분면

| | 준비도 낮음 | 준비도 높음 |
|---|---|---|
| **성숙도 높음** | 정착형 — 준비도는 낮지만 일부 조직에서 분석을 쓰고 있어 1차 정착이 필요 | 확산형 — 6가지 준비도를 모두 갖추고 부분적으로 도입되어 확산 중 |
| **성숙도 낮음** | 준비형 — 데이터·조직·인력·기법·인프라가 부족해 사전 준비가 필요 | 도입형 — 분석 업무·기법은 부족하지만 준비도가 높아 바로 도입 가능 |

## 분석 지원 인프라: 플랫폼

개별 분석 과제마다 시스템을 따로 만들면 복잡도와 비용이 늘어난다. **분석 플랫폼**을 구축해 공동 기능을 제공하고 확장성을 높인다.

| 계층 | 구성 |
|---|---|
| 분석 서비스 제공 계층 | 분석 서비스 제공 엔진, 분석 애플리케이션, 분석 서비스 제공 API |
| 분석 플랫폼 | 데이터 처리 Framework, 분석 엔진, 분석 라이브러리 |
| 운영체제 | OS |
| 하드웨어 | 서버, 스토리지, 네트워크 |

## 데이터 거버넌스

**데이터 거버넌스**는 전사 차원의 모든 데이터에 대해 정책·지침, 표준화, 운영 조직과 책임 등의 표준화된 관리 체계를 수립하고 운영하기 위한 프레임워크와 저장소를 구축하는 것이다. 마스터 데이터, 메타 데이터, 데이터 사전이 중요 관리 대상이다.

| 구성 요소 | 내용 |
|---|---|
| 원칙 (Principle) | 데이터를 유지·관리하기 위한 지침과 가이드 (보안, 품질 기준, 변경 관리) |
| 조직 (Organization) | 데이터를 관리할 조직의 역할과 책임 (데이터 관리자, DB 관리자, 데이터 아키텍트) |
| 프로세스 (Process) | 데이터 관리를 위한 활동과 체계 (작업 절차, 모니터링, 측정 활동) |

### 데이터 거버넌스 체계

| 체계 | 내용 |
|---|---|
| 데이터 표준화 | 데이터 표준 용어 설정, 명명 규칙(Name Rule) 수립, 메타 데이터 구축, 데이터 사전 구축 |
| 데이터 관리 체계 | 메타 데이터와 데이터 사전의 관리 원칙 수립, 데이터 생명주기 관리 방안 수립 |
| 데이터 저장소 관리 (Repository) | 메타 데이터와 표준 데이터를 관리하는 전사 저장소. 워크플로우와 관리용 응용 소프트웨어 지원 |
| 표준화 활동 | 표준 준수 여부 주기적 점검·모니터링, 거버넌스 조직 내 안정적 정착을 위한 변화 관리와 교육 |

### 빅데이터 거버넌스의 특징

- 빅데이터는 양이 매우 많아 모든 데이터를 관리하면 비용이 크게 늘어난다 → **ROI 관점**에서 접근
- 데이터 최적화, 정보보호, 데이터 생명주기 관리, 데이터 카테고리별 관리 책임자 지정이 필요
- 산업 분야별, 데이터 유형별, 정보 거버넌스 요소별로 구분해 작성

## 분석 조직 구조

| 구조 | 특징 | 장점 | 단점 |
|---|---|---|---|
| 집중 구조 | 전사 분석 업무를 별도 분석 전담 조직에서 담당 | 전략적 중요도에 따라 우선순위를 정해 진행 가능 | 현업 부서와 업무가 이원화·중복될 가능성 |
| 기능 구조 | 별도 분석 조직 없이 각 현업 부서에서 직접 분석 | 해당 업무에 특화된 분석 | 전사적 관점의 전략적 핵심 분석이 어렵고, 과거 실적 분석에 국한될 가능성 |
| 분산 구조 | 분석 조직 인력이 현업 부서에 배치되어 업무 수행 | 전사 차원의 우선순위 수행, 분석 결과를 신속하게 실무에 적용, 베스트 프랙티스 공유 | 부서 분석 업무와 역할 분담을 명확히 해야 함 (업무 과다·이원화 우려) |

## 분석 과제 관리 프로세스

| 단계 | 세부 절차 |
|---|---|
| 과제 발굴 | 분석 아이디어 발굴 → 분석 과제 후보 제안 → 분석 과제 확정 |
| 과제 수행 | 팀 구성 → 분석 과제 실행 → 분석 과제 진행 관리 → 결과 공유·개선 |

분석 과제의 결과물은 **풀(Pool)**로 관리하고 공유해 조직 내 분석 문화를 높인다.

## 분석 교육과 변화 관리

- 분석 도구 사용 교육뿐 아니라 **분석 기획자의 데이터 분석 역량 확보**, 현업 사용자 대상 **분석 기회 발굴·시나리오 작성법** 교육
- 경영층이 사실 기반(Fact-based) 의사결정을 하도록 **분석 문화 정착**
- 분석 조직과 인력이 기존 업무와 충돌하지 않도록 **변화 관리**

# 3과목 · 데이터 분석 | R 기초와 데이터 마트

## R의 특징

R은 통계 분석과 시각화에 특화된 오픈소스 프로그래밍 언어다. ADsP 3과목은 R 코드와 출력 결과를 보여주고 해석하는 문제가 많다.

- 무료 오픈소스, 다양한 패키지(CRAN), 강력한 그래픽 기능
- 인터프리터 언어 (한 줄씩 실행)
- 객체 지향, 함수형 언어
- 인덱스가 **1부터** 시작한다 (파이썬은 0부터)
- 대소문자를 구분한다
- 대입 연산자는 `<-` (또는 `=`)

### 결측 데이터의 유형

| 유형 | 설명 |
|---|---|
| 완전 무작위 결측 (MCAR) | 결측이 다른 변수와 전혀 관계없이 무작위로 발생 |
| 무작위 결측 (MAR) | 결측이 다른 관측 변수와는 관련 있지만, 해당 변수 자체와는 관련 없음 |
| 비무작위 결측 (MNAR) | 결측이 해당 변수 값 자체와 관련 있음 (예: 소득이 높을수록 소득 응답 거부) |

### 결측치 대치 방법

| 방법 | 설명 |
|---|---|
| 완전 분석법 (Completes Analysis) | 결측이 있는 행을 삭제하고 완전한 자료만 분석. 효율성 상실, 통계적 추론 타당성 문제 |
| 평균 대치법 (Mean Imputation) | 비조건부(관측 데이터 평균으로), 조건부(회귀분석으로 예측) |
| 단순 확률 대치법 | 평균 대치의 추정량 표준오차 과소 추정 문제 보완. Hot-deck, Nearest Neighbor |
| 다중 대치법 (Multiple Imputation) | 단순 대치를 여러 번(m번) 수행. **대치 → 분석 → 결합** 3단계 |

## 이상치 처리

**이상치(Outlier)**는 다른 데이터와 크게 동떨어진 값이다. 무조건 삭제하지 않고 원인을 확인한다(입력 오류인지, 실제 특이 사례인지).

- **ESD(Extreme Studentized Deviation)**: 평균 ± 3 표준편차를 벗어나면 이상치
- **사분위수(IQR) 기준**: Q1 − 1.5 × IQR 보다 작거나, Q3 + 1.5 × IQR 보다 크면 이상치. IQR = Q3 − Q1
- **상자 그림(Boxplot)**으로 시각적으로 확인
- 처리: 삭제, 대체(평균·중앙값), 변환(로그), **절단(Trimming)**, **조정(Winsorizing: 상·하한값으로 바꿈)**

:::ex IQR 계산 예
Q1 = 20, Q3 = 40이면 IQR = 20. 하한 = 20 − 30 = −10, 상한 = 40 + 30 = 70. 따라서 75는 이상치, 65는 이상치 아님.
:::

## 데이터 마트와 변수 만들기

**데이터 마트**는 데이터 웨어하우스에서 특정 분석 목적에 맞게 추출한 데이터 집합이다. 분석용 데이터 마트를 잘 만드는 것이 분석 성패를 좌우한다.

| 구분 | 요약 변수 | 파생 변수 |
|---|---|---|
| 정의 | 수집된 정보를 분석에 맞게 종합(aggregate)한 변수 | 사용자가 특정 조건이나 함수로 의미를 부여한 변수 |
| 특징 | 데이터 마트에서 가장 기본. 많은 모델에 공통으로 쓰여 **재활용성 높음** | **주관적**일 수 있어 논리적 타당성이 필요 |
| 예 | 기간별 구매 금액·횟수, 상품별 구매 순서, 단어 빈도 | 근무 시간 구매 지수, 주 구매 매장, 주 활동 지역, 선호 가격대 |

## 탐색적 데이터 분석 (EDA)

**EDA(Exploratory Data Analysis)**는 본격 분석 전에 데이터를 다양한 각도에서 살펴보며 특징을 파악하는 과정이다. 투키(Tukey)가 제시한 4가지 주제:

1. **저항성 (Resistance)** — 일부 이상치에 크게 영향받지 않는 통계량(중앙값 등)을 쓴다
2. **잔차 해석 (Residual)** — 관측값과 모델 예측값의 차이에서 정보를 얻는다
3. **자료 재표현 (Re-expression)** — 로그·제곱근 변환 등으로 해석을 쉽게
4. **현시성 (Graphic Representation)** — 시각화로 데이터 구조를 드러낸다

## 모집단과 표본

- **모집단(Population)**: 알고 싶은 대상 전체. 모집단의 특성값을 **모수(Parameter)**라 한다 (모평균 μ, 모분산 σ²)
- **표본(Sample)**: 모집단에서 뽑은 일부. 표본의 특성값을 **통계량(Statistic)**이라 한다 (표본평균 x̄, 표본분산 s²)
- **전수조사**: 모집단 전체 조사 / **표본조사**: 일부만 조사해 모집단 추론
- 표본조사의 오차: **표본오차**(표본이 모집단을 대표하지 못해 생김) / **비표본오차**(조사·응답·입력 과정의 실수, 표본 크기가 커져도 줄지 않음) / **표본편의**(표본추출 방법 때문에 생기는 편향, 확률화로 줄인다)

## 표본추출 방법

| 방법 | 설명 | 예 |
|---|---|---|
| 단순 무작위 추출 (Simple Random) | 모든 원소가 같은 확률로 뽑히게 무작위 추출 | 번호표 추첨 |
| 계통 추출 (Systematic) | 번호를 매기고 일정 간격(k번째마다)으로 추출 | 1~1000번 중 10번째마다 |
| 집락 추출 (Cluster) | 모집단을 여러 군집으로 나누고 **군집을 무작위로 선택해 군집 전체를 조사**. 군집 내부는 이질적, 군집 간은 동질적 | 학교 20곳 중 3곳을 뽑아 전교생 조사 |
| 층화 추출 (Stratified) | 모집단을 **서로 이질적인 층**으로 나누고 각 층에서 무작위 추출. 층 내부는 동질적, 층 간은 이질적 | 학년별로 나눠 학년마다 30명씩 |

:::warn 집락 vs 층화
- **층화**: 모든 층에서 조금씩 뽑는다. 층 내부 = 동질
- **집락**: 몇 개 집락을 골라 그 안을 전부 조사한다. 집락 내부 = 이질
:::

## 측정 척도

| 척도 | 설명 | 예 | 가능한 연산 |
|---|---|---|---|
| 명목 척도 (Nominal) | 단순히 범주를 구분 | 성별, 혈액형, 출생지 | 같다/다르다 |
| 서열 척도 (Ordinal) | 범주 간 순서가 있음 | 학년, 만족도(상·중·하), 선호 순위 | 대소 비교 |
| 등간 척도 (Interval) | 순서 + 간격이 같음. **절대 0점 없음** | 온도(℃), 지능지수, 연도 | 덧셈·뺄셈 |
| 비율 척도 (Ratio) | 간격 + **절대 0점 있음** | 무게, 키, 나이, 매출액 | 사칙연산 모두 |

명목·서열은 **범주형(질적) 자료**, 등간·비율은 **연속형(양적) 자료**다.

## 기술통계

| 구분 | 통계량 | 설명 |
|---|---|---|
| 중심 경향 | 평균 (Mean) | 모든 값의 합 / 개수. 이상치에 민감 |
| | 중앙값 (Median) | 크기순 정렬 시 가운데 값. 이상치에 강함(저항성) |
| | 최빈값 (Mode) | 가장 자주 나타나는 값 |
| 산포도 | 분산 (Variance) | 편차 제곱의 평균. 표본분산은 n−1로 나눔 |
| | 표준편차 (SD) | 분산의 제곱근. 원 단위와 같다 |
| | 범위 (Range) | 최댓값 − 최솟값 |
| | 사분위수 범위 (IQR) | Q3 − Q1 |
| | 변동계수 (CV) | 표준편차 / 평균. 단위가 다른 자료의 산포 비교 |
| 분포 모양 | 왜도 (Skewness) | 비대칭 정도. 0이면 대칭 |
| | 첨도 (Kurtosis) | 뾰족한 정도. 정규분포의 첨도 3 (초과첨도 0) |

### 왜도와 대푯값의 위치

| 분포 | 왜도 | 대푯값 크기 |
|---|---|---|
| 오른쪽 꼬리가 긴 분포 (Positive Skew) | 왜도 > 0 | 최빈값 < 중앙값 < 평균 |
| 대칭 분포 | 왜도 = 0 | 평균 = 중앙값 = 최빈값 |
| 왼쪽 꼬리가 긴 분포 (Negative Skew) | 왜도 < 0 | 평균 < 중앙값 < 최빈값 |

평균은 항상 **꼬리 쪽**으로 끌려간다고 기억하면 된다.

### 그래프

- **히스토그램**: 연속형 자료의 도수분포. 막대 사이 간격 없음
- **막대 그래프**: 범주형 자료. 막대 사이 간격 있음
- **상자 그림(Box Plot)**: 최솟값, Q1, 중앙값, Q3, 최댓값과 이상치
- **산점도(Scatter Plot)**: 두 연속형 변수의 관계
- **줄기-잎 그림**: 값의 분포를 숫자 그대로 표시

## 확률

- **확률**: 0 ≤ P(A) ≤ 1, 표본공간 S에 대해 P(S) = 1
- **덧셈 법칙**: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
- **배반사건**(동시에 일어날 수 없음): P(A ∩ B) = 0 → P(A ∪ B) = P(A) + P(B)
- **조건부 확률**: P(B | A) = P(A ∩ B) / P(A)
- **독립사건**: P(A ∩ B) = P(A) · P(B), 이때 P(B | A) = P(B)
- **베이즈 정리**: P(A | B) = P(B | A) · P(A) / P(B)

:::warn 배반 ≠ 독립
배반사건(교집합이 0)은 한쪽이 일어나면 다른 쪽은 절대 일어나지 않으므로 서로 영향을 준다 → 독립이 아니다(둘 다 확률이 0보다 클 때).
:::

### 확률변수와 기댓값

- **확률변수**: 표본공간의 각 결과에 실수를 대응시킨 함수. 이산형(셀 수 있음) / 연속형
- **기댓값** E(X) = Σ x · P(x) (이산형), ∫ x f(x) dx (연속형)
- **분산** V(X) = E(X²) − [E(X)]²
- 선형 변환: E(aX + b) = aE(X) + b, V(aX + b) = a²V(X)
- 독립일 때: E(X + Y) = E(X) + E(Y), V(X + Y) = V(X) + V(Y)

## 확률분포

### 이산형 확률분포

| 분포 | 설명 | 평균 | 분산 |

| 포아송분포 | 단위 시간·공간에서 사건이 발생하는 횟수 (콜센터 전화 수, 책 한 페이지 오타 수) | λ | λ |

| 다항분포 | 결과가 3가지 이상인 시행의 반복 | | |
| 초기하분포 | 비복원 추출에서 성공 횟수 | | |

### 연속형 확률분포

| 분포 | 설명 |
|---|---|
| 균일분포 | 모든 구간에서 확률밀도가 같음 |
| 정규분포 N(μ, σ²) | 평균을 중심으로 좌우 대칭 종 모양. 평균 ± 1σ 약 68%, ± 2σ 약 95%, ± 3σ 약 99.7% |
| 표준정규분포 Z | 평균 0, 분산 1. Z = (X − μ) / σ |
| t 분포 | 정규분포와 비슷하지만 꼬리가 두꺼움. 모분산을 모를 때 평균 검정. **자유도가 커지면 정규분포에 가까워짐** |
| 카이제곱(χ²) 분포 | 표준정규 확률변수 제곱의 합. 분산 검정, 범주형 자료 검정(적합도·독립성). 0 이상, 오른쪽 꼬리 |
| F 분포 | 두 카이제곱 변수 비율. **두 집단 분산 비교**, 분산분석(ANOVA) |
| 지수분포 | 사건 사이의 대기 시간 (포아송 과정) |

### 중심극한정리

모집단의 분포와 상관없이, 표본 크기 n이 충분히 크면(보통 30 이상) **표본평균의 분포는 정규분포에 가까워진다**. 평균은 μ, 분산은 σ²/n이다.

## 추정

- **점추정**: 모수를 하나의 값으로 추정 (표본평균으로 모평균 추정)
- 좋은 추정량의 조건: **불편성**(기댓값이 모수와 같음), **효율성**(분산이 작음), **일치성**(표본이 커질수록 모수에 가까워짐), **충족성**
- **구간추정**: 모수가 포함될 것으로 기대되는 범위를 신뢰수준과 함께 제시
  - 모분산을 알 때 모평균의 95% 신뢰구간: x̄ ± 1.96 × σ/√n
  - 99% 신뢰구간은 ± 2.58 × σ/√n
  - 신뢰수준이 높을수록 구간이 넓어지고, 표본이 클수록 구간이 좁아진다

:::warn 95% 신뢰구간의 뜻
"같은 방법으로 신뢰구간을 100번 만들면 그중 약 95번은 모수를 포함한다"는 뜻이다. "모수가 이 구간에 있을 확률이 95%"라는 표현은 엄밀히는 틀렸다(모수는 고정된 값).
:::

## 가설검정

| 용어 | 설명 |
|---|---|
| 귀무가설 H₀ | "차이가 없다", "효과가 없다". 기각 여부를 판단하는 대상 |
| 대립가설 H₁ | 연구자가 입증하려는 주장. "차이가 있다" |
| 검정통계량 | 표본으로 계산한 검정용 값 (t, z, χ², F) |
| 유의수준 α | 1종 오류를 범할 최대 허용 확률. 보통 0.05 |
| 유의확률 p-value | 귀무가설이 참이라는 가정에서 지금보다 극단적인 결과가 나올 확률 |
| 기각역 | 귀무가설을 기각하게 되는 검정통계량의 범위 |

판정: **p-value < α 이면 귀무가설 기각** (대립가설 채택).

| | H₀ 참 | H₀ 거짓 |
|---|---|---|
| **H₀ 채택** | 옳은 결정 (1 − α) | **2종 오류 β** |
| **H₀ 기각** | **1종 오류 α** | 옳은 결정, 검정력 (1 − β) |

- **1종 오류**: 귀무가설이 참인데 기각 (없는 효과를 있다고 판단)
- **2종 오류**: 귀무가설이 거짓인데 채택 (있는 효과를 놓침)
- 표본 크기가 고정이면 α를 줄이면 β가 커진다 (트레이드오프)

## 모수 검정

모집단이 정규분포를 따른다는 가정하에 모수(평균·분산)에 대해 검정한다.

| 검정 | 목적 | 예 |
|---|---|---|
| 일표본 t검정 | 한 집단 평균이 특정 값과 같은지 | 과자 평균 무게가 100g인가 |
| 대응표본 t검정 (Paired) | 같은 대상의 전후 비교 | 다이어트 전후 몸무게 |
| 독립표본 t검정 | 두 독립 집단의 평균 비교 (사전에 등분산 검정) | 남녀 평균 키 |
| 분산분석 (ANOVA) | 세 집단 이상의 평균 비교, F 통계량 | 세 가지 비료의 수확량 |
| 카이제곱 검정 | 적합도 검정, 독립성 검정, 동질성 검정 (범주형) | 성별과 선호 정당의 관련성 |

```r
t.test(x, mu = 100)                   # 일표본
t.test(before, after, paired = TRUE)  # 대응표본
t.test(a, b, var.equal = TRUE)        # 독립표본 (등분산)
var.test(a, b)                        # 등분산 검정 (F)
aov(y ~ group, data = df)             # 일원분산분석
chisq.test(table(df$sex, df$party))   # 독립성 검정
shapiro.test(x)                       # 정규성 검정
```

### 정규성 검정

- **Shapiro-Wilk 검정**: 표본이 정규분포를 따르는지. p-value > 0.05면 정규성 만족
- **Kolmogorov-Smirnov(K-S) 검정**: 표본 분포가 특정 분포와 같은지
- **Q-Q plot**: 점들이 대각선 위에 있으면 정규성
- **Anderson-Darling 검정**

## 비모수 검정

모집단 분포에 대한 가정(정규성)을 하지 않는다. 관측값의 **순위나 부호**를 이용한다. 표본이 작거나 정규성이 만족되지 않을 때 쓴다.

| 비모수 검정 | 대응하는 모수 검정 | 용도 |
|---|---|---|
| 부호 검정 (Sign Test) | 일표본 t | 중앙값 검정, 차이의 부호만 이용 |
| 윌콕슨 부호순위 검정 | 일표본·대응표본 t | 차이의 부호와 크기 순위 |
| 만-위트니 U 검정 (윌콕슨 순위합) | 독립표본 t | 두 독립 집단 비교 |
| 크루스칼-왈리스 검정 | 일원분산분석 | 세 집단 이상 비교 |
| 런 검정 (Run Test) | | 관측값이 무작위로 나타났는지 |
| 스피어만 순위 상관 | 피어슨 상관 | 두 변수의 순위 상관 |

# 3과목 · 데이터 분석 | 상관·회귀·다변량·시계열 분석

## 상관분석

두 변수 사이의 **선형적 관계의 방향과 강도**를 분석한다. 상관계수는 −1 ~ 1 사이이며, 인과관계를 뜻하지 않는다.

| 구분 | 피어슨 상관계수 | 스피어만 상관계수 |
|---|---|---|
| 대상 | 등간·비율 척도 (연속형) | 서열 척도 |
| 관계 | 선형 관계 | 비선형 단조 관계도 측정 |
| 가정 | 정규성 | 비모수 (순위 이용) |
| R | `cor(x, y, method = "pearson")` | `cor(x, y, method = "spearman")` |

- 상관계수 r = 공분산 / (X 표준편차 × Y 표준편차)
- 공분산은 단위에 따라 값이 달라지지만 상관계수는 단위와 무관하다
- `cor.test(x, y)`로 상관계수가 0인지 검정 (H₀: ρ = 0)
- 켄달의 타우(Kendall's τ)도 순위 상관계수다

## 회귀분석

하나 이상의 **독립변수(설명변수)**가 **종속변수(반응변수)**에 미치는 영향을 추정하는 분석.

### 선형회귀의 가정

| 가정 | 설명 | 확인 방법 |
|---|---|---|
| 선형성 | 독립변수와 종속변수가 선형 관계 | 산점도 |
| 독립성 | 잔차들이 서로 독립 (자기상관 없음) | **더빈-왓슨(Durbin-Watson) 검정**, 2에 가까우면 독립 |
| 등분산성 | 잔차의 분산이 독립변수 값과 관계없이 일정 | 잔차 vs 적합값 그래프 |
| 비상관성 | 관측치들의 잔차끼리 상관이 없음 | |
| 정상성 (정규성) | 잔차가 정규분포를 따름 | Q-Q plot, Shapiro-Wilk |

### 단순선형회귀

Y = β₀ + β₁X + ε. **최소제곱법(OLS)**으로 잔차 제곱합이 최소가 되는 β를 찾는다.

- **SST**(총 변동) = **SSR**(회귀로 설명되는 변동) + **SSE**(설명되지 않는 잔차 변동)
- **결정계수 R²** = SSR / SST = 1 − SSE / SST. 0 ~ 1, 모델의 설명력
- 단순선형회귀에서 R² = (상관계수 r)²
- **수정된 결정계수(Adjusted R²)**: 독립변수가 늘어나면 R²는 무조건 커지므로, 변수 개수를 고려해 보정한 값

### R 회귀분석 출력 읽기

```r
fit <- lm(mpg ~ wt + hp, data = mtcars)
summary(fit)
```

### 다중회귀와 다중공선성

- **다중공선성(Multicollinearity)**: 독립변수들끼리 강한 상관관계가 있어 회귀계수 추정이 불안정해지는 문제
- 진단: **VIF(분산팽창요인) > 10**이면 다중공선성이 심하다고 본다. 상관계수 행렬, 공차한계(Tolerance = 1/VIF) < 0.1
- 해결: 변수 제거, 주성분 회귀(PCA), 릿지 회귀
- **더미 변수**: 범주형 변수를 회귀에 넣을 때 범주 수 − 1 개의 0/1 변수로 변환

### 변수 선택 방법

| 방법 | 설명 |
|---|---|
| 전진 선택법 (Forward) | 절편만 있는 모델에서 시작해 중요한 변수를 하나씩 추가. 한번 들어간 변수는 제거되지 않음 |
| 후진 제거법 (Backward) | 모든 변수를 넣고 시작해 덜 중요한 변수를 하나씩 제거 |
| 단계적 방법 (Stepwise) | 추가와 제거를 반복하며 최적 모델 탐색 |
| 모든 가능한 조합 | 모든 변수 조합을 비교 (변수가 많으면 계산량 폭증) |

선택 기준: **AIC**(Akaike), **BIC**(Bayesian, 변수 수에 더 큰 벌점) — **값이 작을수록 좋은 모델**. R에서는 `step(fit, direction = "both")`.

### 정규화(규제) 선형회귀

과대적합을 막기 위해 회귀계수 크기에 벌점을 준다.

| 모델 | 벌점 | 특징 |
|---|---|---|
| 릿지 (Ridge) | **L2**: λΣβ² | 계수를 0에 가깝게 줄이지만 0으로 만들지는 않음. 다중공선성 완화 |
| 라쏘 (Lasso) | **L1**: λΣ\|β\| | 일부 계수를 정확히 0으로 만들어 **변수 선택** 효과 |
| 엘라스틱넷 (Elastic Net) | L1 + L2 | 릿지와 라쏘의 장점 결합 |

λ(람다)가 클수록 규제가 강해진다.

### 로지스틱 회귀 (예고)

종속변수가 범주형(0/1)일 때 쓴다. 다음 장(분류 모형)에서 자세히 다룬다.

## 다차원 척도법 (MDS)

**MDS(Multi-Dimensional Scaling)**는 객체 간 거리(유사성)를 보존하면서 저차원(보통 2차원) 공간에 배치해 관계를 시각화하는 방법이다.

- 개체들 사이의 **유클리드 거리 행렬**을 이용
- 적합도는 **스트레스(Stress) 값**으로 평가. 0에 가까울수록 원래 거리를 잘 보존한다 (0.05 이하면 매우 좋음, 0.15 이상이면 부적합으로 보는 편)
- 계량적 MDS(등간·비율 척도), 비계량적 MDS(서열 척도)
- R: `cmdscale(dist(x), k = 2)`

## 주성분 분석 (PCA)

**PCA(Principal Component Analysis)**는 상관관계가 있는 여러 변수를 **서로 상관없는 소수의 주성분**으로 축약하는 차원 축소 기법이다.

- 첫 번째 주성분이 데이터의 분산을 **가장 많이** 설명하고, 두 번째는 첫 번째와 직교하면서 남은 분산을 가장 많이 설명
- 변수 단위가 다르면 **표준화(상관행렬 사용)** 후 분석
- 주성분 개수 결정
  - **누적 기여율**(Cumulative Proportion)이 **80% 이상**이 되는 지점
  - **스크리 그래프(Scree Plot)**에서 기울기가 완만해지는 지점(Elbow) 바로 전
  - 고유값(Eigenvalue)이 1 이상인 주성분 (카이저 기준)
- 다중공선성 해결, 시각화, 노이즈 제거에 활용

```r
p <- princomp(USArrests, cor = TRUE)
summary(p)
```

```text
Importance of components:
                          Comp.1    Comp.2    Comp.3     Comp.4
Standard deviation     1.5748783 0.9948694 0.5971291 0.41644938
Proportion of Variance 0.6200604 0.2474413 0.0891408 0.04335752
Cumulative Proportion  0.6200604 0.8675017 0.9566425 1.00000000
```

Comp.2까지 누적 기여율이 86.8% → **주성분 2개**로 원래 변수 4개 정보의 약 87%를 설명한다.

:::warn PCA vs 요인분석
PCA는 분산을 최대한 보존하는 **차원 축소**가 목적이고, 요인분석은 변수들 뒤에 숨은 **잠재 요인**을 찾는 것이 목적이다. PCA의 주성분은 서로 **직교(상관 0)**한다.
:::

## 시계열 분석

**시계열 자료**는 시간 순서대로 관측된 자료다. 시계열 분석을 하려면 먼저 **정상성(Stationarity)**을 만족해야 한다.

### 정상성 조건

1. 평균이 일정하다 → 일정하지 않으면 **차분(Differencing)**
2. 분산이 시점에 의존하지 않는다 → 일정하지 않으면 **변환(로그 등)**
3. 공분산은 시차(lag)에만 의존하고 특정 시점에 의존하지 않는다

- **백색잡음(White Noise)**: 평균 0, 분산 일정, 자기상관이 없는 순수 무작위 시계열
- **차분**: 현 시점 값 − 이전 시점 값. 계절성이 있으면 계절 차분

### 시계열 모형

| 모형 | 설명 | ACF (자기상관함수) | PACF (부분자기상관함수) |
|---|---|---|---|
| AR(p) 자기회귀 | 현재 값이 과거 p개 값으로 설명됨 | 지수적으로 감소 | **p+1 시차부터 절단 (0)** |
| MA(q) 이동평균 | 현재 값이 과거 q개 오차항으로 설명됨 | **q+1 시차부터 절단 (0)** | 지수적으로 감소 |
| ARMA(p, q) | AR + MA | 감소 | 감소 |
| ARIMA(p, d, q) | **d번 차분**하면 ARMA(p, q)가 되는 비정상 시계열 | | |

:::ex ARIMA 읽기
- ARIMA(0, 1, 1): 1번 차분하면 MA(1)
- ARIMA(1, 2, 3): 2번 차분하면 ARMA(1, 3)
- ARIMA(p, 0, q) = ARMA(p, q), ARIMA(0, 0, q) = MA(q)
:::

### 분해 시계열

시계열을 영향 요인별로 분해한다.

| 요인 | 설명 |
|---|---|
| 추세 요인 (Trend) | 장기적으로 증가·감소하는 경향 |
| 계절 요인 (Seasonal) | 요일·월·분기처럼 고정된 주기로 반복 |
| 순환 요인 (Cyclical) | 경기 순환처럼 알려지지 않은 주기로 변동 |
| 불규칙 요인 (Irregular) | 위 요인으로 설명되지 않는 오차 |

R: `decompose(ts_data)`, `stl()`. 그 밖에 **이동평균법**(일정 기간 평균으로 추세 파악), **지수평활법**(최근 관측치에 더 큰 가중치)이 있다.

# 3과목 · 데이터 분석 | 정형 데이터 마이닝

## 데이터 마이닝 개요

**데이터 마이닝**은 대용량 데이터에서 의미 있는 패턴·규칙을 찾아 의사결정에 활용하는 것이다. 통계분석이 가설·가정에 따른 분석이라면, 데이터 마이닝은 다양한 알고리즘으로 데이터에서 직접 의미를 찾는다.

| 구분 | 지도 학습 (Supervised) | 비지도 학습 (Unsupervised) |
|---|---|---|
| 정답(목표변수) | 있음 | 없음 |
| 목적 | 분류(Classification), 예측(Prediction) | 군집, 연관 규칙, 차원 축소 |
| 기법 | 회귀, 로지스틱 회귀, 의사결정나무, 인공신경망, SVM, k-NN, 나이브 베이즈, 앙상블 | k-means, 계층적 군집, DBSCAN, SOM, 연관 분석, PCA |

데이터 마이닝 5단계: **목적 정의 → 데이터 준비 → 데이터 가공 → 기법 적용 → 검증**

## 데이터 분할과 모델 평가 방법

과대적합을 막고 일반화 성능을 보려면 데이터를 나눈다.

| 데이터 | 역할 | 비율 예 |
|---|---|---|
| 훈련용 (Training) | 모델 학습 | 50~60% |
| 검증용 (Validation) | 하이퍼파라미터 조정, 과대적합 확인 | 20~30% |
| 테스트용 (Test) | 최종 성능 평가 (학습에 절대 사용 금지) | 20% |

| 방법 | 설명 |
|---|---|
| 홀드아웃 (Hold-out) | 데이터를 무작위로 훈련용과 테스트용으로 한 번 나눔 (예: 7:3) |
| k-겹 교차검증 (k-fold CV) | 데이터를 k개로 나눠 1개는 검증, k−1개는 학습. k번 반복 후 평균 |
| LOOCV | k = n인 교차검증. 1개씩 빼고 학습 |
| 부트스트랩 (Bootstrap) | **복원 추출**로 학습 데이터 생성. n이 크면 한 번도 선택되지 않는 데이터가 약 **36.8%** → 이것을 검증용으로 사용 |
| 계층별 k-겹 교차검증 | 불균형 데이터에서 각 폴드의 클래스 비율을 원래와 같게 유지 |

- **과대적합(Overfitting)**: 훈련 데이터에는 잘 맞지만 새 데이터에서 성능이 떨어짐 (모델이 너무 복잡)
- **과소적합(Underfitting)**: 훈련 데이터에도 잘 맞지 않음 (모델이 너무 단순)
- **불균형 데이터**: 언더샘플링(다수 클래스 줄이기), 오버샘플링(소수 클래스 늘리기, SMOTE), 가중치 조정

## 로지스틱 회귀분석

종속변수가 **범주형(0/1)**일 때 쓰는 회귀. 결과는 0~1 사이 확률이다.

- **오즈(Odds)** = p / (1 − p). 성공 확률이 실패 확률의 몇 배인가
- **로짓(Logit)** = ln(odds) = β₀ + β₁X → 선형식
- 확률 p = 1 / (1 + e^−(β₀ + β₁X)) → **시그모이드 함수**
- **exp(β₁)**: X가 1 증가할 때 **오즈가 exp(β₁)배** 증가 (오즈비)
- 추정은 최소제곱법이 아니라 **최대우도추정법(MLE)**
- R: `glm(y ~ x, family = binomial, data = df)`
- 모형 적합도: 이탈도(Deviance) — Null deviance와 Residual deviance의 차이가 클수록 설명력 있음, 카이제곱 검정

:::ex 해석 예
`glm` 결과 x의 계수가 0.693이면 exp(0.693) ≈ 2 → x가 1 증가할 때 성공 오즈가 2배가 된다.
:::

## 의사결정나무

데이터를 분류 규칙에 따라 나무 구조로 나눠 분류·예측하는 모형.

- 구성: 뿌리 마디(Root), 중간 마디(Internal), 끝 마디(Terminal, Leaf), 부모·자식 마디, 가지(Branch), 깊이(Depth)
- **장점**: 해석이 쉽다(규칙 형태), 변수 스케일·정규성 가정 불필요, 수치형·범주형 모두 처리, 비선형 관계 탐지, 이상치에 덜 민감
- **단점**: 과대적합 위험, 분류 경계 근처에서 오차가 큼, 데이터 변화에 따라 구조가 불안정

### 분리 기준

| 목표변수 | 기준 | 알고리즘 |
|---|---|---|
| 이산형 (분류나무) | **카이제곱 통계량의 p-value** (작을수록 좋은 분리) | CHAID |
| | **지니 지수(Gini Index)** — 불순도. 작을수록 순수 | CART |
| | **엔트로피 지수(Entropy)** — 정보 이득이 큰 쪽으로 분리 | C4.5, C5.0 |
| 연속형 (회귀나무) | **분산분석의 F 통계량 p-value** | CHAID |
| | **분산의 감소량** | CART |

- 지니 지수 = 1 − Σ pᵢ²
- 엔트로피 = − Σ pᵢ log₂ pᵢ

:::ex 지니 지수 계산
한 마디에 ○ 3개, ● 1개가 있으면 p(○) = 3/4, p(●) = 1/4. 지니 = 1 − (9/16 + 1/16) = 6/16 = 0.375. 한 종류만 있으면 지니 = 0(완전 순수), 반반이면 0.5(최대).
:::

### 정지 규칙과 가지치기

- **정지 규칙(Stopping Rule)**: 더 이상 분리하지 않는 조건. 최대 깊이, 마디 최소 관측치 수, 불순도 감소량이 작을 때
- **가지치기(Pruning)**: 과대적합된 가지를 잘라 일반화 성능을 높인다. 검증 데이터로 오분류율이 최소가 되는 지점을 찾음

## 앙상블 기법

여러 모델의 예측을 결합해 단일 모델보다 성능을 높이는 방법.

| 기법 | 방법 | 특징 |
|---|---|---|
| 배깅 (Bagging) | **부트스트랩** 표본으로 여러 모델을 만들고 결과를 **투표(Voting)/평균** | 분산을 줄여 안정성 향상. 가지치기 없이 최대로 성장한 나무 사용 |
| 부스팅 (Boosting) | 약한 모델을 **순차적으로** 만들며 이전 모델이 **틀린 데이터에 가중치**를 더 줌 | 편향을 줄여 정확도 향상. 과대적합 주의. AdaBoost, GBM, XGBoost, LightGBM |
| 랜덤 포레스트 (Random Forest) | 배깅 + 각 분기마다 **변수를 무작위로 일부만** 선택 | 나무들 간 상관을 줄임. 예측력 높지만 해석이 어려움. 변수 중요도 제공 |
| 스태킹 (Stacking) | 여러 모델의 예측값을 입력으로 다시 메타 모델 학습 | |

## 인공신경망

사람 뇌의 뉴런 구조를 본뜬 모형. **입력층 → 은닉층 → 출력층**으로 구성되고, 노드 사이 연결 가중치를 학습한다.

- **퍼셉트론**: 입력 × 가중치의 합에 활성화 함수를 적용. 단층 퍼셉트론은 XOR 문제를 풀지 못함 → **다층 퍼셉트론(MLP)**으로 해결
- **역전파(Backpropagation)**: 출력 오차를 뒤로 전달하며 가중치를 갱신
- **기울기 소실(Vanishing Gradient)**: 층이 깊어질수록 시그모이드 미분값이 작아져 앞쪽 가중치가 학습되지 않음 → ReLU로 완화

| 활성화 함수 | 출력 | 용도 |
|---|---|---|
| 계단 함수 (Step) | 0 또는 1 | 초기 퍼셉트론 |
| 부호 함수 (Sign) | −1 또는 1 | |
| 시그모이드 (Sigmoid) | 0 ~ 1 | 이진 분류 출력층 (로지스틱 회귀와 같음) |
| tanh | −1 ~ 1 | |
| ReLU | max(0, x) | 은닉층에서 가장 많이 사용, 기울기 소실 완화 |
| 소프트맥스 (Softmax) | 각 클래스 확률, 합 = 1 | **다중 분류** 출력층 |

- 은닉층·은닉 노드가 너무 많으면 과대적합, 너무 적으면 과소적합
- 장점: 비선형 문제, 잡음에 강함 / 단점: 결과 해석이 어렵다(블랙박스), 초기 가중치에 따라 결과가 달라짐, 학습 시간이 김

## 그 밖의 분류 모형

| 모형 | 설명 |
|---|---|
| 서포트 벡터 머신 (SVM) | 두 클래스 사이 **마진(Margin)을 최대화**하는 초평면을 찾음. 경계에 가장 가까운 점이 **서포트 벡터**. 비선형은 **커널 트릭**(RBF, 다항 커널)으로 고차원에 매핑 |
| 나이브 베이즈 (Naive Bayes) | 베이즈 정리를 이용하고, 모든 특성이 서로 **조건부 독립**이라고 가정. 스팸 메일 분류에 많이 사용 |
| k-최근접 이웃 (k-NN) | 새 데이터와 가장 가까운 k개 이웃의 다수결로 분류. 학습 과정 없음(게으른 학습). k가 작으면 과대적합, 크면 과소적합. 거리 계산 전 **표준화** 필요 |

## 분류 모형 평가

### 혼동 행렬 (Confusion Matrix)

| | 예측 Positive | 예측 Negative |
|---|---|---|
| **실제 Positive** | TP (True Positive) | FN (False Negative) |
| **실제 Negative** | FP (False Positive) | TN (True Negative) |

:::fig cm

| 지표 | 공식 | 뜻 |
|---|---|---|
| 정확도 (Accuracy) | (TP + TN) / 전체 | 전체 중 맞춘 비율 |
| 오분류율 (Error Rate) | (FP + FN) / 전체 = 1 − 정확도 | |
| 정밀도 (Precision) | TP / (TP + FP) | **Positive라고 예측한 것** 중 실제 Positive |
| 재현율 = 민감도 (Recall, Sensitivity, TPR) | TP / (TP + FN) | **실제 Positive** 중 Positive로 예측 |
| 특이도 (Specificity, TNR) | TN / (TN + FP) | **실제 Negative** 중 Negative로 예측 |
| 거짓 긍정률 (FPR) | FP / (FP + TN) = 1 − 특이도 | |
| F1 Score | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) | 정밀도와 재현율의 조화평균 |
| 카파 통계량 (Kappa) | (정확도 − 우연 일치 확률) / (1 − 우연 일치 확률) | 우연히 맞힌 것을 보정 |

:::warn 정밀도 vs 재현율
- 스팸 필터: 정상 메일을 스팸으로 잘못 거르면 곤란 → **정밀도** 중시
- 암 진단: 실제 환자를 놓치면 위험 → **재현율(민감도)** 중시
- 둘은 보통 트레이드오프다. 분류 기준값(threshold)을 낮추면 재현율↑, 정밀도↓
:::

### ROC 곡선과 AUC

- **ROC 곡선**: 분류 기준값을 바꿔가며 **x축 FPR(1 − 특이도)**, **y축 TPR(민감도)**을 그린 곡선
- **AUC**(Area Under Curve): ROC 곡선 아래 면적. 1에 가까울수록 좋고, **0.5면 무작위 분류**와 같다
- 곡선이 **왼쪽 위 모서리**에 가까울수록 좋은 모델

### 이익 도표와 향상도 곡선

- **이익 도표(Gain Chart)**: 예측 확률 순으로 데이터를 정렬해 등급(보통 10%씩)을 나누고, 각 등급의 반응률을 표시
- **향상도(Lift)** = 해당 등급의 반응률 / 전체 반응률. 상위 등급의 향상도가 높고 아래로 갈수록 급격히 감소하면 좋은 모델
- 마케팅에서 "상위 10% 고객에게만 캠페인하면 몇 배 효과인가"를 판단할 때 사용

## 군집 분석

비지도 학습. 관측치들을 **유사성(거리)**에 따라 군집으로 묶는다. 군집 내 동질성↑, 군집 간 이질성↑.

### 거리 측도

| 연속형 거리 | 설명 |
|---|---|
| 유클리드 거리 | √Σ(xᵢ − yᵢ)². 가장 일반적인 직선 거리 |
| 맨해튼 거리 | Σ\|xᵢ − yᵢ\|. 격자 도로를 따라가는 거리 |
| 민코프스키 거리 | (Σ\|xᵢ − yᵢ\|ᵐ)^(1/m). m=1이면 맨해튼, m=2면 유클리드 |
| 체비셰프 거리 | max\|xᵢ − yᵢ\|. 가장 큰 차이 |
| 표준화 거리 | 각 변수를 표준편차로 나눠 단위 차이 제거 |
| 마할라노비스 거리 | 변수들의 **공분산(상관관계)까지 고려**한 거리 |

| 범주형 거리·유사도 | 설명 |
|---|---|
| 단순 일치 계수 | 전체 속성 중 일치하는 속성의 비율 |
| 자카드 계수 | \|A ∩ B\| / \|A ∪ B\|. 0~1 |
| 코사인 유사도 | 두 벡터 사이 각도의 코사인. 문서 유사도에 많이 사용 |

:::ex 거리 계산
A(1, 2), B(4, 6): 유클리드 = √(9 + 16) = 5, 맨해튼 = 3 + 4 = 7, 체비셰프 = 4.
:::

### 계층적 군집

가까운 관측치끼리 차례로 묶어가는 방법. **덴드로그램(Dendrogram)**으로 결과를 표시하고, 원하는 높이에서 잘라 군집 수를 정한다. 군집 수를 미리 정하지 않아도 된다. 한번 묶이면 다시 나뉘지 않는다.

| 연결법 | 군집 간 거리 정의 |
|---|---|
| 최단 연결법 (Single) | 두 군집에서 **가장 가까운** 관측치 간 거리. 고립된 군집을 찾는 데 유리, 사슬 모양 |
| 최장 연결법 (Complete) | 두 군집에서 **가장 먼** 관측치 간 거리. 둥근 군집 |
| 평균 연결법 (Average) | 모든 관측치 쌍 거리의 평균 |
| 중심 연결법 (Centroid) | 두 군집 중심 간 거리 |
| 와드 연결법 (Ward) | 군집 내 **오차제곱합(SSE)의 증가량**이 최소가 되게 병합. 크기가 비슷한 군집 |

R: `hclust(dist(x), method = "ward.D2")`, `cutree(hc, k = 3)`

### 비계층적 군집: k-means

1. 군집 수 k를 정하고 초기 중심 k개를 임의로 선택
2. 각 관측치를 가장 가까운 중심의 군집에 할당
3. 각 군집의 평균으로 중심을 다시 계산
4. 중심이 변하지 않을 때까지 2~3 반복

- 장점: 단순하고 빠름, 대용량 데이터에 적합
- 단점: **k를 미리 정해야** 함, 초기 중심에 따라 결과가 달라짐, **이상치에 민감**(평균 사용), 볼록하지 않은(비구형) 군집은 잘 찾지 못함
- 이상치에 강한 변형: **k-medoids (PAM)** — 평균 대신 실제 관측치(메도이드)를 중심으로
- k 선택: **엘보우 기법**(군집 내 제곱합 SSE 감소가 완만해지는 지점), **실루엣 계수**(−1 ~ 1, 1에 가까울수록 군집이 잘 됨)

### 그 밖의 군집 방법

| 방법 | 설명 |
|---|---|
| DBSCAN | **밀도 기반**. 반경 eps 안에 최소 점 개수(minPts) 이상이면 군집. 임의 모양의 군집, 노이즈(이상치) 구분 가능. k를 미리 정하지 않음 |
| 혼합 분포 군집 | 데이터가 여러 확률분포(보통 정규분포)의 혼합에서 나왔다고 가정. **EM 알고리즘**으로 모수 추정 (E단계: 각 데이터가 어느 분포에 속할지 기댓값 계산, M단계: 모수 갱신). 확률적으로 군집 소속 결정 |
| SOM (자기조직화지도) | 코호넨(Kohonen)이 개발한 비지도 신경망. 고차원 데이터를 **2차원 격자**에 표시. 입력층과 경쟁층(출력층)으로 구성, **경쟁 학습**으로 승자 노드 결정. 역전파를 쓰지 않아 빠름 |

## 연관 분석

**연관 분석(장바구니 분석)**은 "A를 사면 B도 산다"처럼 항목 간 **조건-결과(if-then)** 규칙을 찾는다.

| 지표 | 공식 | 뜻 |
|---|---|---|
| 지지도 (Support) | P(A ∩ B) = A와 B를 함께 포함한 거래 수 / 전체 거래 수 | 규칙이 얼마나 자주 나타나는가 |
| 신뢰도 (Confidence) | P(B \| A) = P(A ∩ B) / P(A) | A를 산 거래 중 B도 산 비율 |
| 향상도 (Lift) | P(B \| A) / P(B) = P(A ∩ B) / (P(A) · P(B)) | A를 샀을 때 B를 살 확률이 평소보다 몇 배인가 |

- **향상도 = 1**: 두 품목이 서로 **독립** (관계 없음)
- **향상도 > 1**: **양의 상관** (함께 구매, 보완재 — 빵과 버터)
- **향상도 < 1**: **음의 상관** (대체재 — 콜라와 사이다)

:::ex 계산 예
전체 거래 100건 중 빵 40건, 우유 50건, 빵과 우유 함께 20건.

- 지지도(빵 → 우유) = 20 / 100 = 0.2
- 신뢰도(빵 → 우유) = 20 / 40 = 0.5
- 향상도 = 0.5 / 0.5 = 1 → 빵 구매와 우유 구매는 서로 독립
:::

- **Apriori 알고리즘**: 최소 지지도 이상인 **빈발 항목 집합**만 찾아 규칙을 만든다. "어떤 항목 집합이 빈발하지 않으면 그 상위 집합도 빈발하지 않는다"는 원리로 계산량을 줄임
- **FP-Growth**: 트리 구조(FP-Tree)로 데이터베이스를 2번만 스캔해 Apriori보다 빠름
- **순차 패턴 분석**: 시간 순서를 고려한 연관 분석 (노트북을 산 고객이 한 달 뒤 마우스를 산다)
- 장점: 결과가 if-then 규칙이라 이해 쉬움, 목적변수가 없는 비목적성 분석, 계산이 간단
- 단점: 품목 수가 늘면 계산량이 기하급수적으로 증가, 적절한 품목 수준 결정이 어려움, 거래가 적은 품목은 규칙 발견에서 제외됨

1) x축 민감도, y축 특이도
2) x축 1 − 특이도, y축 민감도
3) x축 정밀도, y축 재현율
4) x축 민감도, y축 1 − 특이도
> 정답 2 | x축 FPR(1 − 특이도), y축 TPR(민감도).

Q. 부트스트랩에 대한 설명으로 옳지 않은 것은?
1) 복원 추출 방법을 사용한다
2) 한 번도 선택되지 않는 데이터 비율은 약 36.8%이다
3) 데이터가 적을 때 유용하다
4) 비복원 추출로 k개의 폴드를 만든다
> 정답 4 | 비복원으로 k개 폴드를 만드는 것은 k-겹 교차검증이다.

Q. 여러 개의 약한 학습기를 순차적으로 만들고, 이전 모델이 잘못 분류한 데이터에 가중치를 주는 앙상블 기법은?
1) 배깅
2) 부스팅
3) 랜덤 포레스트
4) 보팅
> 정답 2 | 부스팅(AdaBoost, GBM, XGBoost 등)이다.

Q. 로지스틱 회귀에서 변수 x의 회귀계수가 β일 때 exp(β)의 의미는?
1) x가 1 증가할 때 확률이 β만큼 증가
2) x가 1 증가할 때 오즈가 exp(β)배 증가
3) x가 1 증가할 때 로그 오즈가 exp(β)배 증가
4) x와 y의 상관계수
> 정답 2 | exp(β)는 오즈비. x가 1단위 증가할 때 오즈가 exp(β)배 된다.

Q. 군집 내 오차제곱합의 증가량이 최소가 되도록 군집을 병합하는 계층적 군집 방법은?
1) 최단 연결법
2) 최장 연결법
3) 평균 연결법
4) 와드 연결법
> 정답 4 | 와드(Ward) 연결법이다.

Q. k-means 군집에 대한 설명으로 옳지 않은 것은?
1) 군집 수 k를 미리 정해야 한다
2) 이상치에 민감하다
3) 초기 중심값에 따라 결과가 달라질 수 있다
4) 밀도 기반으로 임의 모양의 군집을 잘 찾는다
> 정답 4 | 밀도 기반으로 임의 모양 군집을 찾는 것은 DBSCAN이다.

Q. 전체 거래 1,000건 중 A 포함 200건, B 포함 250건, A와 B 동시 포함 100건이다. A → B의 향상도는?
1) 0.5
2) 1
3) 2
4) 2.5
> 정답 3 | 신뢰도 = 100/200 = 0.5, P(B) = 250/1000 = 0.25, 향상도 = 0.5 / 0.25 = 2.

Q. 의사결정나무에서 목표변수가 이산형일 때 사용하는 분리 기준이 아닌 것은?
1) 카이제곱 통계량의 p-value
2) 지니 지수
3) 엔트로피 지수
4) 분산의 감소량
> 정답 4 | 분산의 감소량과 F 통계량은 연속형 목표변수(회귀나무)의 분리 기준이다.

Q. 지니 지수가 가장 큰(가장 불순한) 마디는? (○, ● 두 종류)
1) ○○○○
2) ○○○●
3) ○○●●
4) ○●●●
> 정답 3 | 두 종류가 반반일 때 지니 = 1 − (0.25 + 0.25) = 0.5로 최대다.

Q. 코호넨이 개발한 비지도 신경망으로, 고차원 데이터를 2차원 격자에 표현하는 군집 방법은?
1) DBSCAN
2) SOM
3) 혼합 분포 군집
4) k-medoids
> 정답 2 | SOM(Self-Organizing Map)은 입력층과 경쟁층으로 구성되고 경쟁 학습을 한다.

3) 연결화

2) 결과 기반 책임 원칙 고수
3) 알고리즘 접근 허용

> 정답 2 | (데이터의 가치와 미래)

Q. 데이터 사이언스의 구성 요소 중 IT 영역에 해당하지 않는 것은?
1) 시그널 프로세싱
2) 데이터 웨어하우징
3) 프로그래밍
4) 스토리텔링
> 정답 4 | 스토리텔링은 비즈니스 분석(소프트) 영역이다. (데이터 사이언스)

Q. 분석 대상이 무엇인지 모르지만 분석 방법은 아는 경우, 기존 방식으로 새로운 지식을 얻는 분석 유형은?
1) 최적화
2) 솔루션
3) 통찰
4) 발견
> 정답 3 | 대상 Unknown, 방법 Known = 통찰(Insight). (분석 기획의 이해)

Q. CRISP-DM에서 '모델 적용성 평가'가 수행되는 단계는?
1) 데이터 이해
2) 모델링
3) 평가
4) 전개
> 정답 3 | 평가 단계: 분석 결과 평가, 모델링 과정 평가, 모델 적용성 평가. (분석 기획의 이해)

Q. 빅데이터 분석 방법론의 분석 기획 단계 산출물로 프로젝트 범위를 정의한 문서는?
1) WBS
2) SOW
3) ERD
4) 데이터 정의서
> 정답 2 | SOW(Statement Of Work). WBS는 프로젝트 정의 및 계획 수립의 산출물. (분석 기획의 이해)

Q. 분석 과제 우선순위를 시급성 기준으로 정할 때, 포트폴리오 사분면에서 두 번째로 수행할 영역은?

2) 2사분면
3) 3사분면
4) 4사분면

Q. 분석 성숙도 모델의 평가 부문이 아닌 것은?
1) 비즈니스 부문
2) 조직·역량 부문
3) IT 부문
4) 재무 부문
> 정답 4 | 비즈니스, 조직·역량, IT 3개 부문이다. (분석 마스터 플랜)

Q. R에서 `x <- c(2, 4, 6, 8)`일 때 `x[x > 3 & x < 8]`의 결과는?
1) 4 6
2) 4 6 8
3) 2 4 6
4) 6 8
> 정답 1 | 3보다 크고 8보다 작은 값은 4, 6. (R 기초)

Q. 결측값이 해당 변수의 값 자체와 관련되어 발생하는 경우는?
1) MCAR
2) MAR
3) MNAR
4) NULL
> 정답 3 | 비무작위 결측(MNAR). 예: 소득이 높은 사람일수록 소득 응답을 거부. (R 기초와 데이터 마트)

Q. 표본평균의 분포가 표본 크기가 커질수록 정규분포에 가까워진다는 정리는?
1) 대수의 법칙

3) 베이즈 정리

Q. 세 개 이상 집단의 평균을 비교하는 모수 검정과, 그에 대응하는 비모수 검정의 짝으로 옳은 것은?
1) t검정 – 부호 검정

3) 분산분석 – 만-위트니 U 검정
4) 카이제곱 검정 – 런 검정

Q. 유의수준 0.05에서 p-value가 0.03으로 나왔다. 옳은 해석은?

2) 귀무가설을 기각한다
3) 2종 오류가 발생했다
4) 검정력이 0.97이다

Q. 회귀분석 결과에서 '수정된 결정계수'를 사용하는 이유는?

2) 잔차의 정규성을 검정하기 위해
3) 다중공선성을 제거하기 위해
4) 회귀계수의 부호를 결정하기 위해
> 정답 1 | (회귀분석)

Q. 시계열 모형 ARIMA(2, 1, 0)에 대한 설명으로 옳은 것은?

Q. 암 진단 모델에서 실제 환자를 놓치지 않는 것이 가장 중요할 때 중시해야 할 지표는?

Q. 랜덤 포레스트에 대한 설명으로 옳지 않은 것은?
1) 배깅에 변수의 무작위 선택을 더했다
2) 여러 나무의 결과를 투표로 결합한다
3) 단일 의사결정나무보다 해석이 쉽다
4) 변수 중요도를 제공한다
> 정답 3 | 나무가 여러 개라 단일 나무보다 해석이 어렵다. (정형 데이터 마이닝)

Q. 마할라노비스 거리에 대한 설명으로 옳은 것은?
1) 변수 간 상관관계를 고려한 거리다

3) 각 차이의 절댓값 합이다
4) 가장 큰 차이 하나만 본다
> 정답 1 | 공분산 행렬을 이용해 변수 간 상관을 고려한다. ③은 맨해튼, ④는 체비셰프. (군집 분석)

Q. 향상도(Lift)가 1보다 작을 때의 해석으로 옳은 것은?
1) 두 품목은 서로 독립이다
