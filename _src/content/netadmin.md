# 자격증 소개 | 네트워크관리사 2급은 어떤 자격증인가

## 한 줄로 설명하면

한국정보통신자격협회(ICQA)가 시행하는 **국가공인 민간자격**이다. 네트워크 기초 이론, TCP/IP, 서버 운영체제(Windows Server·Linux), 네트워크 장비를 다루고, 실기에서는 **랜 케이블 제작과 서버·장비 설정**을 직접 한다. 네트워크 분야의 국내 입문 자격으로 가장 많이 딴다.

:::tip 이런 사람에게 맞다
- 네트워크 엔지니어, 서버·인프라 운영, 보안 관제를 희망하는 사람
- 응시 자격 없이 바로 볼 수 있는 네트워크 자격을 찾는 사람
- CCNA나 정보보안기사 전에 네트워크 기초를 다지고 싶은 사람
:::

## 시험 한눈에

| 항목 | 내용 |
|---|---|
| 시행 | 한국정보통신자격협회 (ICQA, icqa.or.kr) |
| 필기 | 객관식 50문항 / 50분, 100점 만점 60점 이상 |
| 필기 과목 | 네트워크 일반 · TCP/IP · NOS(네트워크 운영체제) · 네트워크 운용기기 |
| 실기 | 1 SET(1~20문항) / 80분, 작업형·서술형·선택형, 60점 이상 |
| 실기 내용 | LAN 전송매체(케이블 제작) · 네트워크 설계·구축 · TCP/IP · NOS · 네트워크 운용기기 |
| 응시 자격 | 필기는 제한 없음. 실기는 필기 합격일로부터 2년 이내 |
| 시행 횟수 | 연 4회 내외 (회차 공고 확인) |

## 따면 어디에 쓰나

- 네트워크 유지보수, 서버·인프라 운영, 보안 관제 직무 서류에서 **네트워크 실무 기초** 증명
- 공공기관·공기업 전산 직무 가산점이나 우대 자격으로 쓰이는 경우가 있다
- 2급을 따면 **1급 응시 자격**이 생긴다

## 난이도와 준비 기간

- 필기는 기출 유형이 반복되어 비교적 쉬운 편이다
- **실기는 케이블 제작과 Windows Server·라우터 설정을 직접 해 봐야** 한다. 눈으로만 보면 작업형에서 막힌다
- 비전공자 기준 필기 2~4주, 실기 3~4주

## 함께 보면 좋은 자격증 · 추천 순서

- 함께 → **리눅스마스터 2급** (서버 운영체제)
- 다음 → **CCNA** (시스코 장비 심화), **네트워크관리사 1급**
- 보안 쪽 → **정보보안(산업)기사**

:::exam 준비할 때 알아 둘 것
- 이 교본은 시험 범위를 정리한 자료다. 실기는 **랜 케이블을 직접 만들어 보고**, 가상 머신에 Windows Server를 설치해 설정 화면을 익혀야 한다
- 라우터 설정 문제는 Packet Tracer 같은 시뮬레이터로 명령어를 직접 쳐 보면 금방 익숙해진다
- 서브넷 계산은 필기·실기 모두 나온다. 손으로 매일 몇 문제씩 풀어 두자
:::

## 더 자세한 정보는 여기서 확인

- **한국정보통신자격협회 ICQA** (icqa.or.kr): 시험 일정, 접수, 응시료, 출제 기준, 합격자 발표, 1급 응시 자격
- **각 기관 채용공고 / 잡알리오** (job.alio.go.kr): 공공기관별 자격증 가산점·우대 여부

시험 일정·응시료·출제 기준은 해마다 바뀔 수 있다. **응시 전에 위 공식 사이트에서 최신 공고를 꼭 확인**하자.

## 자주 묻는 질문

- **Q. 비전공자도 되나요?** 필기는 응시 자격이 없고 기초 이론 위주라 처음 시작해도 된다.
- **Q. CCNA랑 뭐가 달라요?** 네트워크관리사는 국내 자격이고 한국어로 보며 Windows Server 설정까지 다룬다. CCNA는 시스코 장비 중심의 국제 자격이고 영어로 본다.
- **Q. 필기 붙고 실기 떨어지면?** 필기 합격일로부터 2년 안에 실기를 다시 볼 수 있다.

# 네트워크 일반 | OSI 모델과 데이터 통신

## OSI 7계층

| 계층 | 이름 | 하는 일 | PDU | 장비·프로토콜 |
|---|---|---|---|---|
| 7 | 응용 | 사용자 서비스 | 데이터 | HTTP, FTP, SMTP, DNS, Telnet, SNMP |
| 6 | 표현 | 암호화, 압축, 코드 변환 | 데이터 | JPEG, MPEG, ASCII |
| 5 | 세션 | 연결 설정·유지·종료, 동기화 | 데이터 | NetBIOS, RPC |
| 4 | 전송 | 종단 간 신뢰성, 흐름·오류 제어 | **세그먼트** | TCP, UDP |
| 3 | 네트워크 | 경로 선택(라우팅), 논리 주소 | **패킷** | IP, ICMP, ARP, 라우터 |
| 2 | 데이터 링크 | 물리 주소(MAC), 프레임, 오류 검출 | **프레임** | 이더넷, PPP, HDLC, 스위치, 브리지 |
| 1 | 물리 | 비트 전송, 전기 신호 | 비트 | 케이블, 허브, 리피터 |

## 데이터 통신 기초

| 개념 | 설명 |
|---|---|
| **단방향 (Simplex)** | 한쪽으로만 (TV 방송) |
| **반이중 (Half Duplex)** | 양방향이지만 동시에는 한쪽만 (무전기) |
| **전이중 (Full Duplex)** | 동시에 양방향 (전화) |
| 직렬 / 병렬 전송 | 한 비트씩 / 여러 비트 동시 |
| 동기 / 비동기 전송 | 클록에 맞춰 블록 단위 / 문자마다 시작·정지 비트 |
| **CSMA/CD** | 유선 이더넷. 전송 전 확인, **충돌 감지** 후 재전송 |
| **CSMA/CA** | 무선 LAN. **충돌 회피** (RTS/CTS) |
| 오류 검출 | 패리티, **CRC**, 체크섬, 해밍 코드(오류 정정) |
| 다중화 | FDM(주파수), TDM(시간), WDM(파장, 광), CDM(코드) |

## 네트워크 토폴로지

| 형태 | 특징 |
|---|---|
| **버스** | 한 케이블에 모두 연결. 설치 쉬움, 케이블 고장 시 전체 영향 |
| **스타** | 중앙 장비(스위치)에 연결. 관리 쉬움, 중앙 장비 고장 시 전체 영향. 현재 LAN 대부분 |
| **링** | 원형 연결. 토큰 링 |
| **메시** | 모든 노드 연결. 신뢰성 높음, 비용 큼. 필요 회선 수 **n(n−1)/2** |
| 트리 | 계층형 |

| 범위 | 설명 |
|---|---|
| LAN | 건물·캠퍼스 |
| MAN | 도시 |
| WAN | 국가·대륙 |
| PAN | 개인 주변 (블루투스) |

## 전송매체와 LAN 표준

| 매체 | 특징 |
|---|---|
| **UTP** | 비차폐 꼬임쌍선. 가장 많이 씀, RJ-45, 최대 **100m** |
| STP | 차폐 꼬임쌍선. 간섭에 강함 |
| 동축 케이블 | 10Base2, 10Base5, CATV |
| **광섬유** | 빛으로 전송. 장거리, 고속, 전자기 간섭 없음. 싱글모드(장거리)·멀티모드(단거리) |
| 무선 | 802.11 (Wi-Fi) |

| 카테고리 | 속도 |
|---|---|
| Cat5 | 100Mbps |
| Cat5e | 1Gbps |
| Cat6 | 1Gbps (짧은 거리 10Gbps) |
| Cat6a | 10Gbps |

| 이더넷 표준 | 의미 |
|---|---|
| 10Base-T | 10Mbps, 베이스밴드, 꼬임쌍선 |
| 100Base-TX | 100Mbps (Fast Ethernet) |
| 1000Base-T | 1Gbps, UTP |
| 1000Base-SX / LX | 1Gbps, 광 (단파장 / 장파장) |
| 10GBase-T | 10Gbps, UTP |

**10Base-T 읽는 법**: 10 = 속도(Mbps), Base = 베이스밴드, T = 꼬임쌍선(Twisted pair).

| 802.5 | 토큰 링 |
| 802.11 | 무선 LAN |
| 802.15 | 블루투스 (WPAN) |

# TCP/IP | IP 주소와 서브넷

## IPv4 주소 클래스

| 클래스 | 첫 옥텟 | 기본 마스크 | 첫 비트 |
|---|---|---|---|
| A | 1 ~ 126 | 255.0.0.0 (/8) | 0 |
| B | 128 ~ 191 | 255.255.0.0 (/16) | 10 |
| C | 192 ~ 223 | 255.255.255.0 (/24) | 110 |
| D | 224 ~ 239 | 멀티캐스트 | 1110 |
| E | 240 ~ 255 | 실험용 | 1111 |

127.x.x.x는 **루프백**(자기 자신, 127.0.0.1).

| 사설 IP | 범위 |
|---|---|
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

## 서브넷 계산

:::fig subnet

| 프리픽스 | 마스크 | 블록 | 호스트 수 |
|---|---|---|---|
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /27 | 255.255.255.224 | 32 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 8 | 6 |
| /30 | 255.255.255.252 | 4 | 2 |

:::ex 192.168.1.100/27
블록 32 → 96 ~ 127 구간 → **네트워크 192.168.1.96**, **브로드캐스트 192.168.1.127**, 사용 가능 .97 ~ .126 (30개).
:::

:::ex C클래스 네트워크를 서브넷 6개로 나누기
서브넷 6개 이상 → 2³ = 8 → 호스트 비트에서 3비트를 빌림 → **/27 (255.255.255.224)**, 서브넷마다 호스트 30개.
:::

## TCP/IP 프로토콜

| 계층 (TCP/IP) | 프로토콜 |
|---|---|
| 응용 | HTTP, HTTPS, FTP, SMTP, POP3, IMAP, DNS, DHCP, SNMP, Telnet, SSH |
| 전송 | TCP, UDP |
| 인터넷 | IP, ICMP, IGMP, **ARP**(IP → MAC), RARP(MAC → IP) |
| 네트워크 접근 | 이더넷, PPP |

| TCP | UDP |
|---|---|
| 연결형, 3-way handshake (SYN → SYN/ACK → ACK) | 비연결형 |
| 신뢰성, 순서 보장, 흐름·혼잡 제어 | 빠름, 신뢰성 없음 |
| 헤더 20바이트 이상 | 헤더 8바이트 |

| 포트 | 서비스 | 포트 | 서비스 |
|---|---|---|---|
| 20, 21 | FTP (데이터, 제어) | 110 | POP3 |
| 22 | SSH | 123 | NTP |
| 23 | Telnet | 143 | IMAP |
| 25 | SMTP | 161, 162 | SNMP |
| 53 | DNS | 443 | HTTPS |
| 67, 68 | DHCP (서버, 클라이언트) | 3389 | RDP (원격 데스크톱) |
| 69 | TFTP | 80 | HTTP |

| ICMP 메시지 | 용도 |
|---|---|
| Echo Request / Reply | `ping` |
| Destination Unreachable | 목적지 도달 불가 |
| Time Exceeded | TTL 만료 (`tracert`가 이용) |
| Redirect | 더 좋은 경로 알림 |

## IPv6

| 항목 | 내용 |
|---|---|
| 길이 | **128비트**, 16진수 8그룹 (콜론 구분) |
| 축약 | 앞쪽 0 생략, 연속 0 그룹은 `::`로 **한 번만** |
| 주소 유형 | **유니캐스트, 멀티캐스트, 애니캐스트** (브로드캐스트 없음) |

| 링크 로컬 | FE80::/10 |
| 헤더 | 기본 헤더 40바이트 고정, 확장 헤더 |
| 자동 설정 | SLAAC |
| 전환 기술 | **듀얼 스택, 터널링, 주소 변환(NAT64)** |

# 네트워크 운용기기 | 장비와 라우터 설정

## 네트워크 장비

| 장비 | 계층 | 역할 |
|---|---|---|
| **리피터** | 1 | 신호 증폭·재생 |
| **허브** | 1 | 여러 포트로 신호 전달. 모든 포트가 **하나의 충돌 도메인** |
| **브리지** | 2 | MAC 주소로 세그먼트 분리, 충돌 도메인 분리 |
| **스위치** | 2 | 포트마다 충돌 도메인 분리. MAC 주소 테이블로 전달. VLAN |
| **라우터** | 3 | IP로 경로 선택, **브로드캐스트 도메인 분리** |
| L3 스위치 | 3 | 스위칭 + 라우팅 |
| L4 스위치 | 4 | 포트 기반 부하 분산 |
| L7 스위치 | 7 | 애플리케이션 내용 기반 분산, 보안 |
| **게이트웨이** | 4~7 | 서로 다른 프로토콜 네트워크 연결 |
| 방화벽 / IDS / IPS | | 접근 통제 / 침입 탐지 / 침입 차단 |

| 스위칭 방식 | 설명 |
|---|---|
| **Store-and-Forward** | 프레임 전체 저장 후 오류 검사하고 전달. 정확, 지연 |
| **Cut-Through** | 목적지 MAC만 읽고 바로 전달. 빠름 |
| Fragment-Free | 처음 64바이트만 확인 후 전달 |

| 기술 | 설명 |
|---|---|
| **VLAN** | 물리적 위치와 관계없이 논리적으로 네트워크 분리. 브로드캐스트 도메인 분리 |
| 트렁크 (802.1Q) | 한 링크로 여러 VLAN 전달 |
| **STP** | 스위치 루프 방지 |
| 라우팅 프로토콜 | 정적, **RIP**(거리 벡터, 홉 수, 최대 15), **OSPF**(링크 상태, 비용), BGP(AS 간) |
| NAT | 사설 IP ↔ 공인 IP 변환 |

# 실기 | 작업형 대비

## 랜 케이블 제작

| 핀 | **T568B** | T568A |
|---|---|---|
| 1 | 주황흰 | 초록흰 |
| 2 | 주황 | 초록 |
| 3 | 초록흰 | 주황흰 |
| 4 | 파랑 | 파랑 |
| 5 | 파랑흰 | 파랑흰 |
| 6 | 초록 | 주황 |
| 7 | 갈색흰 | 갈색흰 |
| 8 | 갈색 | 갈색 |

| 케이블 | 구성 | 용도 |
|---|---|---|
| **다이렉트 (Straight)** | 양쪽 같은 규격 (B–B) | PC ↔ 스위치, 스위치 ↔ 라우터 (서로 다른 장비) |
| **크로스오버 (Cross)** | 한쪽 A, 한쪽 B | PC ↔ PC, 스위치 ↔ 스위치, PC ↔ 라우터 (같은 계열 장비) |

외우는 법(T568B): **주흰 주 초흰 파 파흰 초 갈흰 갈**. 1·2번 핀과 3·6번 핀이 송수신에 쓰인다 (100Mbps 기준).

:::ex 제작 순서
1. 피복을 약 2~3cm 벗긴다
2. 꼬인 선을 풀어 T568B 순서로 나란히 편다
3. 끝을 가지런히 약 1.2~1.5cm 남기고 자른다
4. RJ-45 커넥터에 클립이 아래로 가게 하고 끝까지 밀어 넣는다
5. 피복까지 커넥터 안에 들어갔는지 확인하고 압착기로 누른다
6. 테스터로 1~8번 순서대로 불이 들어오는지 확인한다
:::

|---|---|
| 역할 설치 (DNS, DHCP, IIS, AD DS) | 서버 관리자 → 관리 → 역할 및 기능 추가 |
| 사용자 추가·암호 정책 | 컴퓨터 관리 → 로컬 사용자 및 그룹 / 로컬 보안 정책 → 계정 정책 |
| DHCP 범위 | DHCP 관리 콘솔 → IPv4 → 새 범위 (시작·끝 주소, 제외, 임대 기간, 게이트웨이, DNS) |
| DNS 영역·레코드 | DNS 관리자 → 정방향 조회 영역 → 새 호스트(A) |
| IIS 웹 사이트 | IIS 관리자 → 사이트 → 바인딩(포트), 기본 문서 |
| 공유 폴더·NTFS 권한 | 폴더 속성 → 공유 / 보안 탭 |
| 고정 IP | 네트워크 연결 → IPv4 속성 → IP·마스크·게이트웨이·DNS |
| 방화벽 규칙 | 고급 보안이 포함된 Windows Defender 방화벽 → 인바운드 규칙 |

## 실기 서술·선택형 단골

- OSI 계층별 장비·프로토콜 짝짓기
- 서브넷 마스크, 네트워크 주소, 브로드캐스트 주소 계산
- 포트 번호와 서비스 짝짓기
- 라우터 명령어 빈칸 채우기 (`enable secret`, `no shutdown`, `exec-timeout`, `ip route`, `copy r s`)
- 장비 설명에 맞는 장비 고르기 (허브, 스위치, 라우터, 게이트웨이)
