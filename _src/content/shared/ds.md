## 자료구조의 분류

| 선형 구조 | 비선형 구조 |
|---|---|
| 배열, 선형 리스트(연결 리스트), **스택, 큐, 데크** | **트리, 그래프** |

| 구조 | 특징 |
|---|---|
| 배열 | 같은 타입을 연속 저장. 인덱스로 바로 접근, 삽입·삭제 느림 |
| 연결 리스트 | 노드가 포인터로 연결. 삽입·삭제 쉬움, 접근 느림, 포인터 공간 필요 |
| **스택 (Stack)** | **LIFO** (후입선출). 한쪽 끝(Top)에서만 삽입(Push)·삭제(Pop). 함수 호출, 수식 계산, 되돌리기, 재귀, DFS |
| **큐 (Queue)** | **FIFO** (선입선출). 뒤(Rear)에서 삽입, 앞(Front)에서 삭제. 운영체제 작업 스케줄링, 버퍼, BFS |
| 데크 (Deque) | 양쪽 끝에서 삽입·삭제. 입력 제한 데크(Scroll), 출력 제한 데크(Shelf) |

:::ex 스택 연산
A, B, C, D 순서로 들어올 때 Push A, Push B, Pop, Push C, Pop, Push D, Pop, Pop → 출력 순서 **B C D A**.
입력 순서가 1, 2, 3일 때 출력이 **3, 1, 2**는 불가능하다 (3을 먼저 꺼내려면 1, 2가 쌓여 있어 2가 먼저 나와야 함).
:::

## 트리

| 용어 | 뜻 |
|---|---|
| 루트 노드 | 맨 위 노드 |
| 단말 노드 (Leaf) | 자식이 없는 노드 |
| 차수 (Degree) | 노드의 자식 수. **트리의 차수**는 가장 큰 노드 차수 |
| 레벨 / 깊이 | 루트가 레벨 1(또는 0) |
| 형제 노드 | 같은 부모를 가진 노드 |

- **이진 트리**: 자식이 최대 2개. 레벨 k의 최대 노드 수 2^(k−1), 깊이 k인 트리의 최대 노드 수 2^k − 1
- **포화 이진 트리**: 모든 레벨이 꽉 참 / **완전 이진 트리**: 마지막 레벨을 왼쪽부터 채움 / **편향 트리**: 한쪽으로만

### 이진 트리 순회

```text
        A
      /   \
     B     C
    / \     \
   D   E     F
```

| 순회 | 순서 | 결과 |
|---|---|---|
| 전위 (Preorder) | **루트** → 왼쪽 → 오른쪽 | A B D E C F |
| 중위 (Inorder) | 왼쪽 → **루트** → 오른쪽 | D B E A C F |
| 후위 (Postorder) | 왼쪽 → 오른쪽 → **루트** | D E B F C A |

### 수식 표기법

| 표기 | 예 | 변환 방법 |
|---|---|---|
| 중위 (Infix) | `A + B * C` | 일반 수식 |
| 전위 (Prefix) | `+ A * B C` | 괄호를 치고 연산자를 괄호 앞으로 |
| 후위 (Postfix) | `A B C * +` | 괄호를 치고 연산자를 괄호 뒤로 |

:::ex 중위 → 후위 변환
`(A + B) * (C − D)` → 괄호: `((A + B) * (C − D))` → 연산자를 각 괄호 뒤로: `((A B +) (C D −) *)` → `A B + C D − *`
:::

## 그래프

| 구분 | 최대 간선 수 (정점 n개) |
|---|---|
| 무방향 그래프 | n(n−1)/2 |
| 방향 그래프 | n(n−1) |

- 표현: 인접 행렬, 인접 리스트
- 탐색: **DFS**(깊이 우선, 스택), **BFS**(너비 우선, 큐)
- **신장 트리**: 모든 정점을 연결하는 사이클 없는 부분 그래프 (간선 n−1개). **최소 비용 신장 트리**: 크루스칼(간선 가중치 작은 것부터), 프림(정점에서 확장)
- **최단 경로**: 다익스트라

## 정렬

| 정렬 | 방식 | 평균 시간 | 최악 |
|---|---|---|---|
| 삽입 정렬 | 앞의 정렬된 부분에 알맞은 자리로 삽입 | O(n²) | O(n²) |
| 선택 정렬 | 최솟값을 골라 맨 앞과 교환 | O(n²) | O(n²) |
| 버블 정렬 | 인접한 두 값을 비교·교환 | O(n²) | O(n²) |
| 셸 정렬 | 간격을 두고 삽입 정렬 | O(n^1.5) | O(n²) |
| **퀵 정렬** | 피벗(기준)으로 분할 정복 | **O(n log n)** | O(n²) |
| **힙 정렬** | 완전 이진 트리(힙) 이용 | O(n log n) | O(n log n) |
| **병합 정렬** | 반으로 나눠 정렬 후 병합 | O(n log n) | O(n log n) |
| 기수(Radix) 정렬 | 자릿수별로 버킷에 분배 | O(dn) | O(dn) |

:::ex 선택 정렬 1회전
8, 3, 4, 9, 7 → 최솟값 3과 첫 자리 8 교환 → **3**, 8, 4, 9, 7
버블 정렬 1회전: 8,3,4,9,7 → 3,8,4,9,7 → 3,4,8,9,7 → 3,4,8,9,7 → 3,4,8,7,**9**
삽입 정렬 2회전까지: 8,3 → **3,8**,4,9,7 → **3,4,8**,9,7
:::

## 검색과 해싱

| 검색 | 설명 |
|---|---|
| 선형 검색 | 처음부터 하나씩. O(n) |
| **이진 검색** | **정렬된** 자료에서 중간값과 비교해 절반씩 줄임. O(log n). 중간 = (low + high) / 2 |
| 해싱 | 해시 함수로 저장 위치를 바로 계산. O(1) |

**해시 함수**: 제산법(나머지), 제곱법, 폴딩법, 기수 변환법, 숫자 분석법.
**충돌(Collision)**: 다른 키가 같은 주소를 가짐. 같은 주소의 키들을 **동의어(Synonym)**라 한다. 해결: 개방 주소법(선형 탐사), 체이닝.

:::quiz
Q. 후입선출(LIFO) 방식의 자료구조는?
1) 큐
2) 스택
3) 데크
4) 트리
> 정답 2 | 스택이다. 큐는 FIFO.

Q. 다음 트리를 전위 순회한 결과는?

```text
      1
     / \
    2   3
   / \
  4   5
```
1) 1 2 4 5 3
2) 4 2 5 1 3
3) 4 5 2 3 1
4) 1 2 3 4 5
> 정답 1 | 루트 → 왼쪽 → 오른쪽. ②는 중위, ③은 후위.

Q. 중위 표기식 `A * (B + C) − D`를 후위 표기식으로 바꾼 것은?
1) A B C + * D −
2) A B + C * D −
3) − * A + B C D
4) A B C D + * −
> 정답 1 | 괄호 안 B C +, 그다음 A와 곱해 A B C + *, 마지막에 D를 빼서 D −.

Q. 평균 시간 복잡도가 O(n log n)이지만 최악의 경우 O(n²)인 정렬은?
1) 힙 정렬
2) 병합 정렬
3) 퀵 정렬
4) 버블 정렬
> 정답 3 | 퀵 정렬은 피벗 선택이 나쁘면 O(n²)이 된다.

Q. 정점이 6개인 무방향 그래프가 가질 수 있는 최대 간선 수는?
1) 12
2) 15
3) 30
4) 36
> 정답 2 | n(n−1)/2 = 6 × 5 / 2 = 15.

Q. 이진 검색에 대한 설명으로 옳은 것은?
1) 정렬되지 않은 자료에서도 사용할 수 있다
2) 반드시 자료가 정렬되어 있어야 한다
3) 시간 복잡도는 O(n)이다
4) 해시 함수를 사용한다
> 정답 2 | 정렬된 자료에서 절반씩 범위를 줄인다. O(log n).
:::
