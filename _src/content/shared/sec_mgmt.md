## 정보보호 관리와 거버넌스

| 용어 | 뜻 |
|---|---|
| 정보보호 거버넌스 | 경영진이 정보보호를 전략과 연계해 책임지고 관리하는 체계 |
| 정보보호 정책 | 최상위 문서. 정책 → 표준 → 지침(가이드라인) → 절차 순으로 구체화 |
| CISO | 정보보호 최고책임자 |
| CPO | 개인정보 보호책임자 |
| 정보보호 관리체계 (ISMS) | 정책 수립 → 위험 관리 → 대책 구현 → 사후 관리를 반복하는 체계 (PDCA) |

**PDCA**: Plan(계획) → Do(실행) → Check(점검) → Act(개선).

**보안 대책 유형**: 관리적(정책, 교육, 인사), 물리적(출입 통제, CCTV), 기술적(방화벽, 암호화). 기능별: 예방, 탐지, 교정, 억제, 복구.

## 위험 관리

| 용어 | 뜻 |
|---|---|
| 자산 (Asset) | 보호해야 할 가치 있는 것 (정보, 시스템, 사람, 평판) |
| 위협 (Threat) | 자산에 손해를 끼칠 수 있는 원인 |
| 취약점 (Vulnerability) | 위협이 이용할 수 있는 약점 |
| 위험 (Risk) | 위협이 취약점을 이용해 손실을 낼 가능성 = **자산 가치 × 위협 × 취약점** |

**위험 관리 절차**: 자산 식별·가치 평가 → 위협 평가 → 취약점 평가 → 위험 평가(분석) → 대책 선정 → 잔여 위험 평가·수용.

### 위험 분석 접근법

| 접근법 | 설명 |
|---|---|
| 기준선(베이스라인) 접근 | 표준화된 보호 대책을 체크리스트로 일괄 적용. 빠르고 저렴, 조직 특성 반영 부족 |
| 비정형 접근 | 전문가 경험과 지식으로 분석. 빠르지만 전문가에 의존 |
| 상세 위험 분석 | 자산·위협·취약점을 정형화된 절차로 상세 분석. 정확하지만 시간·비용 큼 |
| 복합 접근 | 중요 시스템은 상세, 나머지는 베이스라인 |

### 정량적 vs 정성적 위험 분석

| 정량적 (숫자) | 정성적 (등급) |
|---|---|
| **ALE**(연간 예상 손실) = **SLE × ARO** | 델파이법(전문가 합의) |
| **SLE**(단일 예상 손실) = **자산 가치(AV) × 노출 계수(EF)** | 시나리오법 |
| 과거 자료 분석법, 수학 공식 접근법, 확률 분포법 | 순위 결정법, 퍼지 행렬법 |
| 비용·효과 분석 가능, 계산 복잡 | 빠르고 쉬움, 주관적 |

:::ex ALE 계산
서버 자산 가치 1억 원, 화재 시 40% 손실(EF 0.4), 화재는 10년에 한 번(ARO 0.1).
SLE = 1억 × 0.4 = 4,000만 원 / ALE = 4,000만 × 0.1 = **400만 원**.
보안 대책 비용이 연 400만 원보다 크면 경제적이지 않다.
:::

### 위험 처리 전략

| 전략 | 설명 | 예 |
|---|---|---|
| **수용** (Acceptance) | 위험을 받아들임 (비용이 더 클 때) | 경미한 위험 |
| **감소·완화** (Reduction) | 대책을 도입해 위험을 줄임 | 방화벽 설치 |
| **회피** (Avoidance) | 위험이 있는 업무를 하지 않음 | 서비스 중단 |
| **전가** (Transfer) | 제3자에게 넘김 | **보험 가입**, 외주 |

## 업무 연속성과 재해 복구

| 용어 | 뜻 |
|---|---|
| **BCP** | 업무 연속성 계획. 재해에도 핵심 업무를 지속 |
| **DRP** | 재해 복구 계획. IT 시스템 복구 중심 |
| **BIA** | 업무 영향 분석. 업무 중단 시 영향과 복구 우선순위 결정 (BCP의 첫 단계) |
| **RTO** | 목표 복구 **시간** (얼마나 빨리) |
| **RPO** | 목표 복구 **시점** (어느 시점 데이터까지) |
| MTD | 최대 허용 중단 시간 |

| 재해 복구 센터 | RTO | 특징 |
|---|---|---|
| 미러 사이트 | **즉시** (0) | 주 센터와 같은 시스템을 실시간 동기화 (Active-Active) |
| 핫 사이트 | 수 시간 이내 | 같은 장비 대기, 데이터 동기화 (Active-Standby) |
| 웜 사이트 | 수일 ~ 수주 | 일부 중요 장비만 |
| 콜드 사이트 | 수주 ~ 수개월 | 공간·전원만 확보 |

**백업**: 전체(Full), **증분**(직전 백업 이후 변경분 — 백업 빠름·복구 느림), **차등**(마지막 전체 백업 이후 변경분 — 복구 시 전체 + 마지막 차등).

## 침해사고 대응과 디지털 포렌식

**침해사고 대응 절차 (7단계)**: 사고 전 준비 → 사고 탐지 → 초기 대응 → 대응 전략 체계화 → 사고 조사 → 보고서 작성 → 해결.

**CERT / CSIRT**: 침해사고 대응팀. 국가 차원: KISA 인터넷침해대응센터(KrCERT).

### 디지털 포렌식

| 기본 원칙 | 의미 |
|---|---|
| **정당성** | 증거가 적법한 절차로 수집되어야 함 (위법 수집 증거 배제) |
| **재현성** | 같은 조건에서 같은 결과가 나와야 함 |
| **신속성** | 휘발성 증거는 빨리 수집 |
| **연계 보관성 (Chain of Custody)** | 수집·이송·분석·보관 단계마다 담당자와 이력을 기록 |
| **무결성** | 수집한 증거가 바뀌지 않았음을 **해시값**으로 증명 |

**휘발성 순서 (먼저 수집)**: 레지스터·캐시 → 메모리(RAM) → 네트워크 상태·실행 중 프로세스 → 임시 파일 → 디스크 → 원격 로그 → 백업 매체.

절차: 사전 준비 → 증거 수집 → 포장·이송 → 조사·분석 → 정밀 검토 → 보고서. 디스크는 **쓰기 방지 장치**를 붙여 **비트 단위 이미징** 후 사본으로 분석한다.

## 인증 제도

| 제도 | 내용 |
|---|---|
| **ISMS-P** | 정보보호 및 개인정보보호 관리체계 인증 (과기정통부·개인정보보호위원회, KISA 운영). 인증 기준 **102개**: 관리체계 수립 및 운영 **16**, 보호대책 요구사항 **64**, 개인정보 처리 단계별 요구사항 **22** |
| ISMS | 정보보호 관리체계만 (80개 = 16 + 64). 일정 기준 이상 사업자는 **의무 인증** |
| 인증 유효 기간 | **3년**, 매년 사후 심사 |
| ISO/IEC 27001 | 국제 정보보호 관리체계 표준 (27002는 통제 항목 지침) |
| **CC (공통평가기준, ISO/IEC 15408)** | 정보보호 제품의 보안성 평가. **보호 프로파일(PP)**: 제품군별 보안 요구사항 / **보안 목표 명세서(ST)**: 특정 제품의 보안 기능 명세. 평가 등급 **EAL1 ~ EAL7** (높을수록 엄격) |
| 보안 기능 확인서 | 국가·공공기관 도입 제품의 보안 기능 시험 |
| **CSAP** | 클라우드 서비스 보안 인증 (공공기관에 클라우드 제공 시) |
| 주요정보통신기반시설 | 국가 안보·경제에 중요한 시설 지정, 매년 취약점 분석·평가 |
| PIA (개인정보 영향평가) | 공공기관이 대규모 개인정보 시스템 구축 시 위험 사전 평가 |

1) 정당성
2) 재현성
3) 연계 보관성
4) 신속성
> 정답 3 | Chain of Custody.

Q. ISMS-P 인증 기준의 총 개수는?
1) 80개
2) 92개
3) 102개
4) 114개
> 정답 3 | 16 + 64 + 22 = 102개. ISMS만은 80개.

Q. 개인정보 보호법상 고유식별정보가 아닌 것은?
1) 주민등록번호
2) 여권번호
3) 운전면허번호
4) 휴대전화번호
> 정답 4 | 고유식별정보는 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호.

Q. 가명정보를 정보주체의 동의 없이 처리할 수 있는 목적이 아닌 것은?
1) 통계 작성
2) 과학적 연구
3) 공익적 기록 보존
4) 마케팅 광고
> 정답 4 | 마케팅은 해당하지 않는다.

Q. 정보보호 제품의 보안성을 평가하는 국제 공통평가기준(CC)의 평가 보증 등급 범위는?
1) EAL0 ~ EAL5
2) EAL1 ~ EAL7
3) Level 1 ~ Level 5
4) A ~ D 등급
> 정답 2 | EAL1부터 EAL7까지.

Q. 기준선(베이스라인) 접근법의 특징으로 옳은 것은?
1) 조직 특성을 정밀하게 반영한다
2) 시간과 비용이 가장 많이 든다
3) 표준화된 보호 대책을 체크리스트로 적용한다
4) 전문가의 경험에만 의존한다
> 정답 3 | 빠르고 저렴하지만 조직 특성 반영이 부족하다.

Q. 동일한 준식별자 값을 가진 레코드가 최소 k개 이상 존재하도록 하는 비식별 적정성 평가 모델은?

3) t-근접성
4) 차분 프라이버시
