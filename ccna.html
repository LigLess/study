    시작하기

    시험 구성과 공부 순서

    CCNA는 어떤 시험인가

    CCNA(Cisco Certified Network Associate)는 시스코가 운영하는 네트워크 엔지니어 입문~실무 자격이다. 시험 코드는 200-301(Implementing and Administering Cisco Solutions) 하나로, 시험 한 번에 합격하면 취득한다. 국내 국가자격이 아니라 국제 벤더 자격이다.

    구분 내용
    시행 Cisco (Pearson VUE 시험 센터 또는 온라인 감독 시험)
    시험 시간 120분
    문항 약 100문항 내외 (시스코는 정확한 수를 공개하지 않음)
    문항 유형 객관식(단일·복수 선택), 드래그 앤 드롭, 시뮬레이션·시뮬렛(CLI에 직접 명령 입력)
    언어 영어, 일본어 (한국어 시험 없음)
    합격 점수 공개하지 않음 (1000점 척도로 결과 표시)
    응시료 약 300달러 (세금 별도, 국가별 차이)
    유효 기간 3년. 재시험 합격 또는 CE 크레딧으로 갱신
    시험 중 특징 이전 문제로 돌아갈 수 없다

    v1.1과 v2.0

    시스코는 2026년 5월 v2.0 출제 범위를 발표했다. 2027년 2월 2일까지는 v1.1, 2027년 2월 3일부터는 v2.0만 응시할 수 있다. 시험 코드는 그대로 200-301이다.

    접수 전에 꼭 다시 확인할 것

    2026년 11월 기준이다. 이 교본은 v2.0 범위를 기준으로 쓰고, v1.1에만 있는 주제(무선 GUI 설정, JSON 해석, SDN 구조 등)도 함께 다룬다. v2.0은 "설명하라"보다 "문제를 진단하고 고쳐라(Troubleshoot, Diagnose)" 문항이 많아졌다. 응시료·정책은 시스코 공식 사이트(cisco.com/go/ccna)에서 확인하자.

    공부 방법

    CCNA는 명령어를 직접 쳐 본 사람만 풀 수 있는 시뮬레이션 문항이 나온다. 무료 실습 도구 Cisco Packet Tracer(Cisco Networking Academy 가입 후 내려받기)를 설치하고 이 교본의 설정을 그대로 따라 쳐 보자.

    1. 1~2주 — 1장 네트워크 기초와 서브넷팅 (매일 10문제)
    2. 3~4주 — 2장 스위칭: VLAN, 트렁크, STP, EtherChannel
    3. 5~6주 — 3장 라우팅: 라우팅 테이블, 정적 라우팅, OSPF
    4. 7주 — 4장 서비스·보안: NAT, ACL, VPN, L2 보안
    5. 8주 — 5장 AI·운영 관리, 실습 랩, 모의 문제

    1. /27 → 마지막 옥텟 블록 크기 32
    2. 77이 들어가는 블록: 64 ~ 95
    3. 네트워크 주소 172.16.45.64, 브로드캐스트 172.16.45.95
    4. 사용 가능 범위 .65 ~ .94, 30개

    /21 → 셋째 옥텟 마스크 248, 블록 크기 8. 37은 32 ~ 39 블록 → 네트워크 10.1.32.0, 브로드캐스트 10.1.39.255, 호스트 2^11 − 2 = 2046개.

    192.168.0.0/16 192.168.0.0 ~ 192.168.255.255

    같은 서브넷끼리는 되고 외부가 안 됨 기본 게이트웨이 누락·오류
    169.254.x.x 주소 DHCP 서버에 닿지 못함
    특정 호스트만 간헐적 끊김 IP 주소 중복
    게이트웨이가 다른 서브넷 주소 마스크 오타 (/24 vs /25)
    이름으로는 안 되고 IP로는 됨 DNS 문제

    2. 10.20.30.40/28의 브로드캐스트 주소는?

      정답 ① 블록 16 → 32 ~ 47.

      정답 ② /23은 2^9 − 2 = 510개.

    4. PC 주소가 169.254.12.7로 잡혀 있다. 가장 가능성 높은 원인은?

      정답 ② APIPA 주소다.

    OSPF 동작 (v2.0 3.3)

    링크 상태 라우팅 프로토콜. 이웃과 LSA를 교환해 같은 영역의 모든 라우터가 같은 LSDB(토폴로지 지도)를 갖고, 각자 SPF(다익스트라)로 최단 경로를 계산한다.

    개념 설명
    메트릭 비용 = 참조 대역폭(기본 100Mbps) / 인터페이스 대역폭. 100M 이상은 모두 1 → auto-cost reference-bandwidth 조정
    Hello / Dead 브로드캐스트·점대점 기본 10초 / 40초
    라우터 ID ① router-id 수동 ② 루프백 최고 IP ③ 활성 물리 인터페이스 최고 IP
    영역 백본 Area 0. 단일 영역 OSPF가 CCNA 범위
    이웃 상태 Down → Init → 2-Way → ExStart → Exchange → Loading → Full
    DR / BDR 이더넷 같은 다중 접근망에서 선출. 인터페이스 우선순위(기본 1, 0이면 불참) → 라우터 ID 높은 순. 선점 없음
    멀티캐스트 224.0.0.5 (모든 OSPF 라우터), 224.0.0.6 (DR/BDR)

    이웃이 맺어지려면 일치해야 하는 것: 서브넷·마스크, 영역 ID, Hello/Dead 타이머, 인증, MTU, 스텁 플래그. 라우터 ID는 달라야 한다. passive 인터페이스에서는 이웃을 맺지 않는다.

    ACL은 위에서부터 순서대로 비교해 처음 일치한 규칙을 적용하고, 끝에는 보이지 않는 암묵적 deny any가 있다.

    종류 번호 조건 배치 원칙
    표준 1–99, 1300–1999 출발지 IP만 목적지에 가깝게

    이름 기반 이름 표준·확장 둘 다 규칙 번호로 중간 삽입·삭제 쉬움

    ACL에서 자주 틀리는 것

    • 규칙 순서: 넓은 규칙(permit ip any any)이 위에 있으면 아래 규칙은 영원히 적용되지 않는다
    • 허용 규칙을 하나도 안 넣으면 암묵적 deny로 전부 막힌다
    • 인터페이스 하나에 방향(in/out)·프로토콜(IPv4/IPv6)마다 ACL 1개만 적용된다
    • show access-lists의 matches 카운터로 실제로 어떤 규칙에 걸리는지 확인한다
