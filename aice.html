    기본 구조

    import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout
from tensorflow.keras.callbacks import EarlyStopping, ModelCheckpoint

model = Sequential([
    Dense(64, activation="relu", input_shape=(X_train.shape[1],)),
    Dropout(0.3),
    Dense(32, activation="relu"),
    Dropout(0.3),
    Dense(1, activation="sigmoid")        # 이진 분류
])
model.summary()

    문제 유형별 마지막 층과 손실 함수

    문제 마지막 층 loss metrics
    이진 분류 Dense(1, activation="sigmoid") binary_crossentropy accuracy
    다중 분류 (정수 레이블) Dense(클래스 수, activation="softmax") sparse_categorical_crossentropy accuracy
    다중 분류 (원-핫 레이블) Dense(클래스 수, activation="softmax") categorical_crossentropy accuracy
    회귀 Dense(1) (활성화 없음) mse mae

    가장 자주 틀리는 조합

    레이블이 0, 1, 2처럼 정수인데 categorical_crossentropy를 쓰면 오류가 난다. 정수면 sparse_가 붙은 것. 원-핫으로 바꾸려면 tf.keras.utils.to_categorical(y).

    컴파일과 학습

    model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])

es = EarlyStopping(monitor="val_loss", patience=5, restore_best_weights=True)
mc = ModelCheckpoint("best_model.h5", monitor="val_loss", save_best_only=True)

history = model.fit(X_train, y_train,
                    validation_data=(X_valid, y_valid),
                    epochs=50, batch_size=32,
                    callbacks=[es, mc], verbose=1)
    용어 의미
    epoch 전체 학습 데이터를 한 번 다 보는 것
    batch_size 가중치를 한 번 갱신할 때 쓰는 샘플 수
    EarlyStopping 검증 손실이 patience번 연속 나아지지 않으면 중단
    ModelCheckpoint 가장 좋은 모델을 파일로 저장
    Dropout(0.3) 학습 때 뉴런 30%를 무작위로 끔 (과대적합 방지)

    학습 곡선과 평가

    plt.plot(history.history["loss"], label="loss")
plt.plot(history.history["val_loss"], label="val_loss")
plt.xlabel("epoch"); plt.legend(); plt.show()

loss, acc = model.evaluate(X_valid, y_valid)
pred = (model.predict(X_valid) > 0.5).astype(int)     # 이진 분류 확률 → 클래스
pred_multi = np.argmax(model.predict(X_valid), axis=1) # 다중 분류

    학습 곡선 읽기

    train loss는 계속 줄어드는데 val loss가 다시 올라가기 시작하면 과대적합이다. 그 지점에서 멈추게 하는 것이 EarlyStopping이다.

    1. 3개 클래스 다중 분류 모델의 출력층으로 알맞은 것은?

      정답 ② 클래스 수만큼, softmax.

    2. 레이블이 0, 1, 2 정수일 때 쓰는 손실 함수는?

      정답 ③ 정수 레이블이면 sparse를 쓴다.

    3. 집값을 예측하는 회귀 모델의 출력층과 손실 함수 조합은?

      정답 ② 회귀는 활성화 없는 Dense(1)과 mse.

    4. 검증 손실이 개선되지 않을 때 학습을 멈추게 하는 콜백은?

      정답 ② EarlyStopping이다.

    5. 학습 데이터 1,000개, batch_size 100이면 1 epoch 동안 가중치는 몇 번 갱신되는가?

      정답 ② 1000 / 100 = 10번.
