# 자격증 교본: ADsP · SQLD · 리눅스마스터 2급

시험 범위 전체를 정리하고 단원마다 확인 문제를 붙인 HTML 교본입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 (세 교본으로 가는 목록) |
| `adsp.html` | ADsP 데이터분석 준전문가: 11개 단원, 문제 88개 |
| `sqld.html` | SQLD SQL 개발자: 12개 단원, 문제 89개 |
| `linux.html` | 리눅스마스터 2급: 13개 단원, 문제 117개 |

## GitHub Pages로 공개하기

1. 이 폴더의 파일을 저장소 맨 위(루트)에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## PDF로 저장하기

- 위쪽 **PDF로 저장**: 원하는 단원을 골라 한 파일로 저장합니다. 정답·해설을 넣을지 뺄지도 고를 수 있습니다.
- 단원 제목 아래 **이 장만 PDF로**: 그 단원만 저장합니다.
- 인쇄 창에서 대상을 **PDF로 저장**, 용지를 **A4**로 고르세요. 단원마다 새 페이지에서 시작하고, 표·코드·문제·그림은 페이지 경계에서 잘리지 않고 다음 장으로 넘어갑니다.
- PC의 Chrome이나 Edge에서 가장 잘 동작합니다.

시험 정보는 2026년 11월 기준입니다. 일정·응시료·출제 기준은 접수 전 공식 사이트(dataq.or.kr, ihd.or.kr)에서 확인하세요.
